## Interpretação
GET /api/admin/config expõe TODAS as configurações do sistema, incluindo chaves
de API secretas, tokens de serviços terceiros, e configurações de segurança.
A única proteção é o JWT de admin (que foi obtido via credenciais default).

## Impacto
- RESEND_API_KEY: permite enviar emails como qualquer endereço verificado no Resend
- TURNSTILE_SECRET_KEY: permite bypass do CAPTCHA
- TMDB_API_KEY: acesso ao TMDB (baixo impacto)
- POSTHOG_KEY: tracking de usuários
- CORS = *: permite qualquer origem fazer requests autenticados
- Dados internos de precificação e configuração expostos

## Recomendação
1. Rotacionar imediatamente todas as chaves de API expostas (RESEND, TURNSTILE, TMDB)
2. Implementar RBAC no endpoint /api/admin/config (só superadmin deve acessar)
3. Mudar CORS de * para origens específicas
4. Não armazenar chaves secretas em config pública
5. Usar variáveis de ambiente para secrets (JWT_SECRET, API keys)
