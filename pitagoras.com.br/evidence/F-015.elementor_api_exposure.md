# F-015 Elementor REST API Exposure — lps/blog.pitagoras.com.br

Alvo: lps.pitagoras.com.br, blog.pitagoras.com.br  
Severidade: Média  
Timestamp: 2026-08-20T08:00:00Z  
Tipo: API Information Disclosure

## Resumo

As REST APIs do Elementor (v1) estão expostas sem autenticação, permitindo  
descoberta de toda a estrutura de rotas e dados não sensíveis.

## Evidência

### LPS — 253 rotas REST expostas
- `/wp-json/` → 307KB de routes (completo)
- `/wp-json/elementor/v1/` → namespace Elementor v1
- `/wp-json/elementor-pro/v1/` → namespace Elementor Pro v1
- `/wp-json/elementor-ai/v1/` → namespace Elementor AI
- `/wp-json/elementor-one/v1/` → namespace Elementor Cloud
- `/wp-json/wp/v2/elementor_snippet` → Snippet exposto (ID 220, "Integration")
- `/wp-json/elementor/v1/documents` → Rota de documentos (GET permission)
- `/wp-json/elementor/v1/form-submissions` → 401 (existe, requer auth)
- `/wp-json/elementor-pro/v1/license/tier-features` → 401 (existe)

### Blog — 200+ rotas expostas
- `/wp-json/` → routes completa
- `/wp-json/elementor/v1/` → namespace Elementor v1
- REST API users: `/wp-json/wp/v2/users` → 200 (10 users enumerados)

## Impacto
- Informação sobre versões de plugins e estrutura interna
- Enumeração de usuários
- Snippet com tracking ID exposto
- Possibilidade de exploração quando novas CVEs surgirem
