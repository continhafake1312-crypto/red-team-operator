# F-013 WordPress Cloudflare Bypass — lps/blog.pitagoras.com.br

Alvo: lps.pitagoras.com.br / blog.pitagoras.com.br  
Severidade: Alta  
Timestamp: 2026-08-20T08:00:00Z  
Técnica: Bypass via conexão direta (Tor/proxychains bloqueado pelo Cloudflare)

## Resumo

O Cloudflare está bloqueando todo tráfego via Tor/proxychains (403 + JS challenge).  
No entanto, conexões diretas (sem proxy) conseguem acessar o WordPress login page.

## Evidência

- Conexão via proxychains → 403 Cloudflare
- Conexão direta via Python requests → 200 (login page obtida)
- Nenhum captcha presente nas páginas de login
- XML-RPC bloqueado (nginx 403)
- Login rate limiting ativo (WP Engine)

## Impacto

O WAF do Cloudflare é bypassável por conexões diretas, permitindo enumeração e ataques.
