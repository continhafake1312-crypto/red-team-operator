1. **WordPress user enumeration** — `wp-json/wp/v2/users`, `?author=1`, `?author=2`, ...
2. **xmlrpc.php brute force / pingback abuse** — vetor clássico WP
3. **Plugin CVE research**:
   - Elementor 4.2.3 (CVE-2024-XXXX se houver)
   - Elementor Pro (CVE histórico)
   - LiteSpeed Cache (múltiplos CVE 2023-2024, alguns RCE)
   - Hello Elementor (raro CVE)
4. **wp-content/plugins enumeration** — listar todos os plugins expostos
5. **wp-content/uploads** — info disclosure, backup files (sql, zip, tar.gz, ai1wm)
6. **wp-admin** direto — `/wp-login.php` redirect → ver para onde vai
7. **ActiveCampaign integration leak** — JS analysis em busca de API keys
8. **Pagamentos** — endpoint de checkout, webhook, integração
9. **Subdomínios** — mail/cpanel/api/admin/dev podem estar fora do CDN
10. **Backup files comuns WP-BR**: ai1wm-backup.zip, backup.sql, debug.log
