## Base URL / Auth
- baseURL: https://api-crm-h4ww.onrender.com
- Auth: Bearer JWT via header `Authorization: Bearer <accessToken>`
- Token storage: localStorage (chaves: `accessToken`, `userData`, `userAbilityRules`)
  - `Ft("...")` = composable useStorage (VueUse) → localStorage
  - Logout: accessToken=null, userData=null, userAbilityRules=null → redirect /login
- Interceptor onRequest injeta `Authorization: Bearer <accessToken>` se houver token

## Multi-tenant (CRÍTICO — como a escola é identificada)
- Frontend extrai hostname: `window.location.hostname.match(/([a-z0-9-]+\.[a-z]+(\.[a-z]+)?)$/i)`
  - Ex: crm.degraucultural.com.br → "degraucultural.com.br"
- Envia como **query param `domain`** em: `GET /auth/user/school?domain=<dominio>`
  - NÃO é header custom, NÃO é subdomínio — é QUERY PARAM `domain`
  - Resposta: `{school:{name, logo_desktop, logo_mobile, id}}`
- Brand logic: `school.id === 1 ? "degrau" : (n==="central" ? "central" : ...)` → escolas Degrau (id=1) e Central de Concursos
- Permissões por escola: `GET /school/permissions` (requer auth)

| GET | /auth/user/logs | (auth) | logs de acesso do user (401 c/ auth) |
| PUT | /auth/user/password | body | altera senha |
| PUT | /auth/user/profile | body | altera perfil |
| GET | /school/permissions | (auth) | permissões CASL da escola |

## Roles (CASL RBAC)
- `admin` → redirect para /overview (dashboard)
- `client` → redirect para /access-control
- Outras: authenticatedOnly, unauthenticatedOnly, public
- Subjects: AclDemo (demo), regras via `userAbilityRules` (localStorage)
