## Interpretação

O n8n é uma plataforma de automação de workflows que permite conectar múltiplos serviços, APIs e bancos de dados. Uma vez autenticado, é possível:
- Criar workflows arbitrários que executam código (Node.js)
- Conectar a serviços internos (bancos de dados, APIs, MinIO)
- Executar comandos no servidor via nós de execução

## Impacto

**Crítico**: Se credenciais forem obtidas (via brute force, CVE ou engenharia social), um invasor pode obter RCE no servidor via workflows n8n. O n8n tem histórico de CVEs de RCE (CVE-2023-37480, CVE-2025-32480, etc.).

## Recomendação

1. Restringir acesso ao n8n por IP ou VPN.
2. Utilizar autenticação de dois fatores.
3. Manter o n8n atualizado.
4. Não expor o endpoint /rest/settings publicamente.
