# F-001 Nginx Version Disclosure
Alvo: vc.focusconcursos.com.br (IP via AWS ELB)
Severidade: Baixa
Timestamp: 2026-08-21T00:00:00Z

## Descrição
O servidor Nginx no host vc.focusconcursos.com.br expõe sua versão exata (1.31.1) nos headers de resposta HTTP.

## Reprodução
curl -I https://vc.focusconcursos.com.br/ 2>&1 | grep -i server
Resposta: Server: nginx/1.31.1

## Impacto
Informação de versão exposta permite que atacantes direcionem CVEs específicas para essa versão do Nginx. Versão 1.31.1 é recente (2025+), mas pode conter vulnerabilidades não divulgadas.

## Recomendação
Configurar `server_tokens off;` no nginx.conf para ocultar versão do servidor.

## Próximo passo
Verificar CVEs para Nginx 1.31.1 durante fase de CVE research.
