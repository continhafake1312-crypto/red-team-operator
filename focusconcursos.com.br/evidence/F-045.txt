# F-045 CKFinder Upload Bypass — Tentativas Exaustivas
**Alvo:** admin.focusconcursos.com.br/ckfinder/connector
**Vetor:** Upload de arquivos via CKFinder (S3 focus-library)
**Severidade:** Alta (upload bloqueado, mas S3 e 1249+ arquivos expostos)
**Timestamp:** 2026-09-04T01:00:00Z

## Resumo
Tentativa exaustiva de realizar upload de arquivos via CKFinder e diretamente no S3 bucket focus-library. **Nenhuma técnica de upload funcionou.** O CKFinder permanece em modo somente leitura para usuários anônimos.

## Técnicas Testadas

### 8. OPTIONS/CORS Preflight

## Análise do Erro 109
O erro CKFinder #109 ("Invalid request") ocorre quando:
- `$_FILES` está vazio (arquivo não recebido pelo PHP)
- Parâmetros obrigatórios ausentes
- Configuração do CKFinder com backend S3 que não permite escrita

**Provável causa:** O CKFinder está configurado com o backend S3 focus-library em modo read-only para usuários não autenticados. A ACL 1023 (Full Control) é retornada pelo Init, mas o backend S3 tem permissões restritas. A configuração do CKFinder (config.php) provavelmente tem `$config['backends'][] = [ 'name' => 'default', 'adapter' => 's3', 'bucket' => 'focus-library', 'key' => '...', 'secret' => '...', ...]` sem permissão de escrita pública.

## Conclusão
O upload via CKFinder está **bloqueado permanentemente** para acesso anônimo. A exploração requer:
1. Sessão administrativa válida do Laravel com permissões de upload
2. Ou credenciais AWS S3 com permissão de escrita no bucket focus-library
3. Ou modificação da configuração do CKFinder

## Recomendações
1. Testar se há uma API de upload alternativa no admin.focusconcursos.com.br
2. Tentar obter sessão admin via SQLi, brute force ou outra vulnerabilidade
3. Buscar chaves AWS nos JS/arquivos que possam ter acesso ao S3
4. Verificar se outros buckets (fc-terraform, fc-database, fc-security) podem conter chaves
