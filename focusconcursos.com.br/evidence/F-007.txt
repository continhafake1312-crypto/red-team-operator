# F-007 Exposição de Arquivos Estáticos (Configuração do Servidor)
Alvo: integration.focusconcursos.com.br, admin.focusconcursos.com.br, lms.focusconcursos.com.br
Severidade: Baixa
Timestamp: 2026-08-22T01:35:00Z

## Reprodução
integration.fc:
- GET /robots.txt → 200 `User-agent: *`
- GET /favicon.ico → 200 (vazio)
- GET /.htaccess → 200 (regras Laravel Apache)
- GET /web.config → 200 (regras Laravel IIS)

admin.fc:
- GET /.htaccess → 200 (regras Laravel Apache)
- GET /mix-manifest.json → 200 (manifesto Laravel Mix com hashes)
- GET /favicon.ico → 200
- GET /robots.txt → 200

lms.fc:
- GET /.htaccess → 200 (idem)
- GET /mix-manifest.json → 200 (manifesto com hashes de assets)

## Output
.htaccess exposto contém:
```
<IfModule mod_rewrite.c>
    <IfModule mod_negotiation.c>
        Options -MultiViews -Indexes
    </IfModule>
    RewriteEngine On
    ...
    RewriteRule ^ index.php [L]
</IfModule>
```

web.config exposto contém regras de rewrite do IIS para Laravel.

mix-manifest.json admin.fc:
```
{"/js/main.js":"/js/main.js?id=57d6a7994e1cbc535ad5","/css/app.css":"/css/app.css?id=d88f19b9278bd8269203","/CKEditor/ckeditor.js":"/CKEditor/ckeditor.js?id=1535d78d95f6b0493b4e",...}
```

## Interpretação
Nginx serve arquivos do diretório public/ sem proteção. Arquivos de configuração do servidor web (Apache/IIS) e manifests de build estão expostos.

## Impacto
- Baixo: .htaccess e web.config revelam estrutura de routing
- mix-manifest.json revela estrutura de assets e versões de arquivos via hash
- Favicon vazio e robots.txt simples (sem Disallow) indicam app mínimo

## Recomendação
- Bloquear acesso a .htaccess, web.config e mix-manifest.json no Nginx
- Configurar `location ~* \.(htaccess|config|json)$ { deny all; }`
