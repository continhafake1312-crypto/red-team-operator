## Notas
- fc-backup testado com 26 prefixes comuns (backup, uploads, images, pdfs, data, exports, logs, config, env, sql, dump, temp, users, admin, www, html, app, db, files, media, static, assets, css, js, src, lib) — todos AccessDenied
- fc-backup arquivos comuns (backup.zip, backup.tar.gz, dump.sql, db.sql, config.php, .env) — HTTP 403
- Nomes como fc-backup, fc-uploads, fc-files, fc-dev, fc-prod, fc-assets são fortemente sugestivos de finalidade (backups, uploads de usuário, arquivos estáticos, dev, produção)

## Recomendação
Embora atualmente privados, estes buckets são alvos de alto valor se credenciais AWS forem obtidas:
- fc-backup: prováveis backups de banco de dados e sistema
- fc-prod: assets de produção
- fc-uploads: uploads de usuários (potencialmente conteúdo sensível)
- fc-dev: ambiente de desenvolvimento
