# F-033 n8n 1.120.4 — Instância Exposta com Rate Limit
Alvo: 18.233.104.160:80
Severidade: Alta (n8n exposto + versão vulnerável)
Timestamp: 2026-08-27T00:40:00Z

## Descrição
Instância n8n workflow automation exposta na porta 80. Versão 1.120.4, que é potencialmente vulnerável a CVE-2026-21858 (file read via form triggers, CVSS 10.0) e CVE-2025-68613 (expression sandbox bypass, CVSS 9.9).

## Versão


## Configuração de Segurança
- Rate limit: Ativo (~5 req/min)
- SSO/SAML/LDAP: Desabilitado
- OIDC: Configurado mas login desabilitado
- Email: Não configurado (forgot password retorna 500)

## Impacto
- n8n exposto publicamente em versão vulnerável
- 11 contas de usuário enumeráveis
- Forgot password indisponível (email não configurado)
- Password reset impossível sem email

## Recomendação
- Atualizar n8n para >= 1.122.0
- Habilitar autenticação de dois fatores
- Restringir acesso por firewall
- Configurar email para password reset
