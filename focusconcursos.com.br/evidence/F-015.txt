# F-015 CKFinder Acessível Sem Autenticação (Read-Only)
Alvo: admin.focusconcursos.com.br (CkFinder/connector)
Severidade: Alta
Timestamp: 2026-08-21

## Descrição
O CKFinder 3 em admin.focusconcursos.com.br permite operações de leitura sem autenticação (Init, GetFiles, GetFolders, Thumbnail). A interface está disponível em `/ckfinder/browser`.

## Reprodução
```
GET /ckfinder/connector?command=Init
→ Retorna configuração do CKFinder, S3 bucket focus-library, ACLs, resource types

GET /ckfinder/connector?command=GetFiles&type=Images&currentFolder=/
→ Lista de imagens com nomes, tamanhos, timestamps

GET /ckfinder/connector?command=GetFolders&type=Files&currentFolder=/
→ Lista de pastas (2020/, FUNDEP/, etc.)
```

## Dados Expostos
- Bucket S3: `focus-library` (sa-east-1) — ACL 1023 (all resources), arquivos privados (403)
- Resource types: Files, Images (com backend S3)
- Estrutura de pastas: pastas por ano (2018-2026), pastas temáticas (FUNDEP, etc.)
- Timestamps de criação/modificação de arquivos
- Upload bloqueado (erro 109: Invalid request)

## Impacto
- Vazamento da estrutura interna de armazenamento de arquivos
- Nomes de arquivos e pastas revelam organização interna
- Timeline de atividade (timestamps)
- Configuração de backend (S3 bucket name, ACLs)
- Se bucket foi deletado (como parece), pode ser takeover candidate

## Recomendação
1. Exigir autenticação para TODAS as operações do CKFinder, incluindo leitura
2. Restringir acesso ao /ckfinder/ por IP ou VPN
3. Remover endpoint /ckfinder/browser da internet pública

## Próximo passo
Monitorar bucket focus-library para takeover (criar bucket com mesmo nome em sa-east-1). Baixar amostra de imagens para análise de metadados.
