# F-039 Payment Gateway Configuration IDs Expostos (GoHighLevel)
Alvo: lps.focusconcursos.com.br (Cloudflare + LeadConnectorHQ)
Severidade: Alta (config de pagamento exposta)
Timestamp: 2026-09-03T18:10:00Z

## Descrição
A landing page lps.focusconcursos.com.br contém no HTML fonte a configuração 
completa de integrações de pagamento do GoHighLevel (LeadConnectorHQ).
Múltiplos Payment Method Configuration IDs (PMC) foram encontrados, expondo 
gateways Stripe, PayPal, Square, Adyen, NMI e outros.

## Detalhes do GHL
- Location ID: `47xvfccyYKbrrjzAocYu`
- GHL API endpoints: `services.leadconnectorhq.com`, `backend.leadconnectorhq.com`
- Integração de pagamento multi-gateway (Stripe, PayPal, Square, Adyen, NMI)
- Hotmart como parceiro de checkout

## Impacto
1. **Payment config exposto**: Permite identificar todos os gateways de pagamento
   integrados ao sistema.
2. **Phishing via PMC IDs**: Os IDs podem ser usados para criar páginas de 
   checkout falsas que imitam a config real.
3. **Abuso de webhook**: Se webhooks de pagamento não forem validados, os PMC IDs
   podem permitir replay de notificações.
4. **Reconhecimento**: Fornece ao atacante a stack completa de pagamento para
   busca de vulnerabilidades específicas.
5. **Chaves públicas Stripe/PayPal**: Embora públicas, confirmam o processador
   e permitem criação de páginas de checkout fraudulentas.

## Recomendação
1. Remover IDs de configuração do HTML público
2. Carregar configurações de pagamento via API autenticada
3. Implementar Content-Security-Policy restritiva
4. Validar webhooks de pagamento com assinatura HMAC
5. Revisar se as chaves públicas expostas precisam ser rotacionadas
