# F-019 S3 Bucket "focus-library" Não Encontrado / CKFinder Backend Inconsistente
Alvo: admin.focusconcursos.com.br → S3 sa-east-1
Severidade: Média
Timestamp: 2026-08-22T02:35:00Z

## Descrição
O CKFinder 3 exposto em admin.focusconcursos.com.br configura como backend o S3 bucket `focus-library` (sa-east-1), retornado pela resposta Init. Entretanto, o bucket NÃO existe mais — todas as tentativas de acesso direto via S3 REST API retornam `NoSuchBucket`.

## Reprodução

### CKFinder Init (bucket configurado)
```
GET /ckfinder/connector?command=Init

→ resourceTypes[0].url: 
  https://s3-sa-east-1.amazonaws.com/focus-library/5333f320-a79d-11e7-be81-833fcc7d70fc/Editor/arquivos/
→ resourceTypes[1].url:
  https://s3-sa-east-1.amazonaws.com/focus-library/5333f320-a79d-11e7-be81-833fcc7d70fc/Editor/imagens/
```

### S3 API — Bucket não existe
```
GET https://s3-sa-east-1.amazonaws.com/focus-library/
→ <?xml version="1.0" encoding="UTF-8"?>
  <Error>
    <Code>NoSuchBucket</Code>
    <Message>The specified bucket does not exist</Message>
    <BucketName>focus-library</BucketName>
  </Error>

GET https://focus-library.s3.sa-east-1.amazonaws.com/
→ NoSuchBucket

GET https://focus-library.s3.amazonaws.com/
→ 404 (bucket DNS não existe)
```

### Acesso a prefixo específico
```
GET https://s3-sa-east-1.amazonaws.com/focus-library/5333f320-a79d-11e7-be81-833fcc7d70fc/
→ NoSuchBucket
```

### Upload (FileUpload, CreateFolder, RenameFolder)
Todas as operações de escrita retornam erro 109 "Invalid request" — upload bloqueado.

## Interpretação
- O bucket S3 `focus-library` foi deletado ou renomeado
- CKFinder continua listando arquivos via cache local ou metadata interna
- Operações de leitura (GetFiles, GetFolders) funcionam (cache/queries internas)
- Operações de escrita (FileUpload, CreateFolder, RenameFolder) falham porque o backend S3 não existe
- ACL=1023 em resource types mas o storage backend está inacessível para escrita

## Impacto
- ALTO: Vazamento de configuração de storage (bucket name, prefixo, região) — mesmo que bucket não exista
- MÉDIO: Upload bloqueado não por security control mas por bucket deletado
- BAIXO: Se bucket for recriado com mesmo nome, toda a estrutura de diretórios está documentada
- BAIXO: Informação de que o storage foi migrado ou descontinuado

## Recomendação
1. Remover CKFinder endpoints públicos (/ckfinder/connector, /ckfinder/browser)
2. Atualizar ou remover configuração de bucket no CKFinder
3. Se bucket foi migrado para novo nome, atualizar resource types

## Próximo passo
- Monitorar se o bucket é recriado (pode permitir upload se políticas de acesso forem restauradas)
- Verificar se há outro bucket com nome similar usando enumeração AWS
