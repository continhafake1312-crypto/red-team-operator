Todos os endpoints testados retornam 401 Unauthorized (protegidos por auth).

## Interpretação
- JS bundles contêm lista exaustiva de todos os endpoints da API REST
- Admin e LMS têm conjuntos de endpoints separados
- Todos os endpoints retornam 401 (protegidos por Sanctum auth middleware)

## Impacto
- Médio: atacante tem mapeamento completo da superfície de API
- Possível análise de vulnerabilidades por endpoint (IDOR, mass assignment)
- Rotas administrativas como /api/finance, /api/heimdall, /api/order expostas

## Recomendação
- Remover source maps de produção ou restringir acesso a JS bundles
- Implementar rate limiting nos endpoints de API

## Próximo passo
- Testar IDOR nos endpoints (ex: /api/person/v1/people/1, /api/order/v1/orders/1)
- Verificar se algum endpoint aceita POST sem auth
