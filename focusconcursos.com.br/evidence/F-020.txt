# F-020 Credential Stuffing — Nenhuma Credencial Válida Encontrada
Alvo: admin.focusconcursos.com.br (Laravel Login)
Severidade: Info
Timestamp: 2026-08-22T02:40:00Z

## Descrição
Realizado teste de credential stuffing contra o endpoint POST /login do admin.focusconcursos.com.br utilizando emails obtidos via OSINT e senhas comuns brasileiras. Nenhuma combinação foi validada.

### Resultado
- Nenhuma combinação email+senha resultou em login bem-sucedido
- Todas retornaram 302 redirect para /login (falha de autenticação)
- O CSRF token é obrigatório para login (presente na página de login)
- Sessão Laravel é criada mesmo em tentativas falhas (admin_session cookie)

## Metodologia
1. GET /login → extrair CSRF token da página
2. POST /login com email, senha e _token
3. Follow redirect (-L) e verificar URL final
4. Se URL final != /login → credencial válida

## Observações
- Nenhuma conta de usuário foi comprometida via força bruta
- O rate limiting não foi observado nos testes (sem bloqueio após múltiplas tentativas)
- A ausência de rate limiting é um finding adicional (permite brute force contínuo)

## Impacto
- Nenhuma conta comprometida até o momento
- Ausência de rate limiting permite ataque contínuo

## Recomendação
1. Implementar rate limiting no endpoint de login
2. Forçar OTP/2FA para contas administrativas
3. Auditoria de logs para detectar tentativas de brute force
