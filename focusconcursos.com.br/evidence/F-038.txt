# F-038 Form API Endpoints Expostos sem Autenticação
Alvo: pagina.focusconcursos.com.br (Express.js + Cloudflare)
Severidade: Média (endpoints de form expostos, rate limiting ativo)
Timestamp: 2026-09-03T18:05:00Z

## Descrição
O host pagina.focusconcursos.com.br expõe endpoints de formulário que aceitam 
requisições POST sem autenticação. Os endpoints `/api/form`, `/form`, `/api/contact`, 
e `/contact` aceitam dados JSON e form-urlencoded, mas retornam erros de validação.

## Reprodução
```bash
# POST /api/form com JSON vazio
curl -sk -X POST "https://pagina.focusconcursos.com.br/api/form" \
  -H "Content-Type: application/json" \
  -d '{}'
# Resposta: {"status":false}

# POST /form com dados
curl -sk -X POST "https://pagina.focusconcursos.com.br/form" \
  -H "Content-Type: application/json" \
  -d '{"email":"test@test.com"}'
# Resposta: {"status":false}

# POST /api/contact com dados
curl -sk -X POST "https://pagina.focusconcursos.com.br/api/contact" \
  -H "Content-Type: application/json" \
  -d '{"email":"test@test.com"}'
# Resposta: HTTP 500 (Internal Server Error) - vazio {}

# Rate limiting ativo: após ~3 requisições consecutivas
curl -sk -X POST "https://pagina.focusconcursos.com.br/api/contact" \
  -H "Content-Type: application/json" \
  -d '{"email":"test@test.com"}'
# Resposta: "Too many requests, please try again later."
```

## Endpoints Confirmados
| Endpoint | Métodos | Resposta Normal | Limite |
|----------|---------|-----------------|--------|
| `/api/form` | POST, GET(404) | `{"status":false}` | ~10 req/min |
| `/form` | POST, GET(404) | `{"status":false}` | ~10 req/min |
| `/api/contact` | POST, GET(404) | HTTP 500 `{}` | ~3 req/min |
| `/contact` | POST, GET(404) | HTTP 500 `{}` | ~3 req/min |

## Tecnologia
- Framework: Express.js
- CDN: Cloudflare (Bot Management ativo, `__cf_bm` cookie)
- Backend: GoHighLevel / LeadConnectorHQ integration (via `form_embed.js` - 46KB)
- Embed script: `/js/form_embed.js` (GHL iframe embedder)
- CORS: `Access-Control-Allow-Origin: *`

## Análise do form_embed.js
O arquivo `/js/form_embed.js` (46KB) é o script de integração GHL que:
- Cria iframes incorporados para formulários/widgets
- Usa Gerenciamento de Estado (`__GHL_EMBED_STATE__`)
- Suporta layouts: POPUP, INLINE, STICKY_SIDEBAR, POLITE_SLIDE_IN
- Inclui lógica de consentimento de cookies e tracking
- NÃO contém endpoints de API hardcoded
- As submissões de formulário vão diretamente para 
  `backend.leadconnectorhq.com` via iframe

## Impacto
1. **Endpoints sem autenticação**: Qualquer pessoa pode enviar requisições POST
2. **Rate limiting inconsistente**: `/api/contact` tem limite mais restritivo (3/min)
   que `/api/form` (10/min)
3. **Server Error**: `/api/contact` retorna HTTP 500 com corpo vazio — pode indicar
   erro de configuração no backend
4. **CORS wildcard**: Qualquer origem pode submeter dados
5. **Potencial para abuso**: Formulários podem ser usados para injeção de dados
   maliciosos, spam, ou brute force de parâmetros

## Recomendação
1. Adicionar autenticação aos endpoints de formulário (CAPTCHA, token CSRF)
2. Corrigir HTTP 500 no `/api/contact`
3. Implementar rate limiting consistente
4. Validar entrada no backend (NoSQLi, SQLi, XSS)
5. Remover CORS wildcard se não necessário
