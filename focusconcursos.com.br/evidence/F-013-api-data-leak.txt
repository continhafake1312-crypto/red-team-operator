# F-013 API Data Leak via Middleware Bypass — NEGATIVO
Alvo: www3.focusconcursos.com.br (Next.js App Router)
Severidade: Info — Nenhum dado sensível vazado
Timestamp: 2026-08-22T02:43:00Z

## Testes Realizados

### Endpoints testados com bypass
| Path | Método | Bypass | Resposta | Dados |
|------|--------|--------|----------|-------|
| `/api/me` | GET | `.rsc` + RSC header | RSC payload (6454 bytes) | Apenas metadados, NotFoundPage |
| `/api/cursos` | GET | `.rsc` + RSC header | RSC payload (6463 bytes) | Apenas metadados, NotFoundPage |
| `/api/concursos` | GET | `.rsc` + RSC header | RSC payload (6475 bytes) | Apenas metadados, NotFoundPage |
| `/api/graphql` | POST | `.rsc` + bypass header | RSC payload | Apenas metadados |
| `/api/me` | POST | bypass header | HTML/RSC | Página redirect |
| `/api/auth/login` | GET | — | 404 | — |
| `/_next/data/...json` | GET | — | HTML (488KB) | Página shell |

### RSC Payload Content (sanitized)
Os payloads RSC continham apenas:
- Referências a chunks JS (webpack)
- Estrutura de rotas: `[domain]/(ecommerce)`, `[domain]/(public)/[slug]`, `[domain]/(token)`
- Componentes: `NotFoundPage`, `Toaster`, `Providers`, `AsyncMetadataOutlet`
- Spinner/Loading: `"animation":"spin 2s linear infinite"`
- Config: `lang:"pt-br"`, fontes Google (Inter)
- Nenhuma string contendo email, senha, token, session, user, admin, ou PII

### Estrutura de Rotas Revelada
- `[domain]/(public)/[slug]/page` — Páginas públicas (Slug dinâmico)
- `[domain]/(ecommerce)/page` — Páginas de e-commerce
- `[domain]/(token)/layout` — Layout com Toaster (provável área logada)
- `[domain]/(public)/(temp)/cursos/page` — Página de cursos temporária

### Conclusão
**Nenhum dado sensível (PII, tokens, credenciais, dados de usuários) foi encontrado.** O app www3 parece ser o frontend público, com dados servidos via API backend separada (provavelmente os endpoints Laravel descobertos em F-004).
