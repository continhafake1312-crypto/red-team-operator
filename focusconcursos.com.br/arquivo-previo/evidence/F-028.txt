# F-028 MySQL/Redis Brute Force — Credential Attempts

**Alvos:**
- MySQL: 18.233.104.160:6034 (MySQL 8.0.42)
- Redis: 18.233.104.160:6035 (Redis key-value store)

**Severidade:** Crítica (serviços expostos)
**Timestamp:** 2026-08-26T20:40:00Z

## Resumo

Ambos os serviços aceitam conexões externas via Tor. MySQL confirma serviço ativo
com mysql_native_password plugin. Redis confirma serviço ativo com autenticação requerida.
Nenhuma credencial válida encontrada nos testes realizados.

### Observações
- Redis usa autenticação por senha (requirepass)
- Mensagem "invalid username-password pair or user is disabled" sugere Redis 6+ com ACL
- AUTH com formato errado retorna "-ERR wrong number of arguments"

## Impacto Atual

- **MySQL**: Porta exposta, sem acesso. Risco de força bruta continua se credenciais forem fracas.
- **Redis**: Porta exposta, sem acesso. Dados em cache (sessões, tokens) protegidos por senha.

## Recomendações

1. Bloquear acesso externo às portas 6034 e 6035 (firewall/security group)
2. Usar senhas fortes (32+ caracteres aleatórios)
3. Usar Redis ACL com users dedicados
4. Para MySQL, trocar para caching_sha2_password e usar certificados TLS
