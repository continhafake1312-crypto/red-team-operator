# F-034 S3 Bucket Discovery — arquivos.grupofocus.com.br

**Alvo:** s3.us-east-1.amazonaws.com/arquivos.grupofocus.com.br
**Severidade:** Alta (bucket S3 com objetos públicos)
**Timestamp:** 2026-09-03T17:25:00Z

## Resumo

Descoberta de um novo bucket S3 utilizado pela plataforma Next.js do focusconcursos.com.br.
O bucket `arquivos.grupofocus.com.br` foi identificado através de análise do HTML da página
principal, que referenciou imagens hospedadas neste bucket (via Next.js Image Optimization).

O bucket NÃO permite listagem pública (404), mas objetos individuais SÃO acessíveis publicamente
sem autenticação (HTTP 200), confirmando ACL pública de leitura para objetos individuais.

## Evidência

### Descoberta
O HTML da página principal focusconcursos.com.br revelou esta URL de imagem:
```
https://s3.us-east-1.amazonaws.com/arquivos.grupofocus.com.br/admin/institution/logoWhite/cltzx3nbn02yahjqn3nge0pkt.webp
```

### Acesso ao Objeto
```
GET https://s3.us-east-1.amazonaws.com/arquivos.grupofocus.com.br/admin/institution/logoWhite/cltzx3nbn02yahjqn3nge0pkt.webp
→ HTTP 200 (12,520 bytes) ✅ Público
```

### Listagem do Bucket
```

→ HTTP 404 ❌ Privado (listagem negada)
```

## Impacto

1. **Objetos públicos:** Qualquer pessoa com o caminho de um objeto pode acessá-lo sem autenticação.
2. **Next.js Image Optimization:** O servidor Next.js do focusconcursos.com.br faz proxy das imagens
   neste bucket, validando indiretamente que o conteúdo é confiável.
3. **Potencial de enumeração:** Se nomes de objetos forem previsíveis, é possível enumerar e baixar
   arquivos.
4. **Bucket de produção:** Contém logos e assets institucionais, sugerindo que outros objetos
   (documentos, PDFs, uploads de usuários) também podem estar acessíveis.
