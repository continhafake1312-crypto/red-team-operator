## ACL Analysis

- ACL: **1023** (Full Control: ALL permissions enabled)
- `deniedExtensions`: **vazio** — nenhuma extensão é bloqueada
- `uploadCheckImages`: **false** — não verifica se upload é imagem
- `maxSize`: 256MB — tamanho máximo de upload muito permissivo

Apesar do ACL 1023, os comandos de escrita estão **bloqueados no backend** (não apenas no ACL),
provavelmente por configuração do servidor ou restrições de rota no Laravel.

## S3 Bucket Focus-Library

- **Bucket:** focus-library (sa-east-1)

## Tentativas de Upload

Todas as tentativas de escrita falharam:
1. **POST FileUpload** → Error 109 (Invalid request)
2. **POST QuickUpload** → Error 109 (Invalid request)
3. **GET QuickUpload** → "Invalid command" (callback JS)
4. **POST com CKFinder CSRF token** → Error 109
5. **POST com campos adicionais** (CKEditor, CKEditorFuncNum) → Error 109

Provavelmente o backend (Laravel) está bloqueando requisições com verificação CSRF,
ou o driver S3 do CKFinder não permite escrita sem credenciais AWS configuradas.

## Testes com JWT Forjado

Token JWT foi forjado usando a chave conhecida `your-256-bit-secret` com payloads:
- `{institution: 4, role: admin}`
- `{institution: 1, role: admin}`

Nenhuma diferença no comportamento do CKFinder foi observada com os tokens JWT,
indicando que o CKFinder **não utiliza** o sistema de autenticação JWT do Laravel.

## Impacto

1. **Bucket S3 de produção exposto**: Todos os arquivos do Editor de conteúdo são públicos
2. **1249+ arquivos enumeráveis**: Material didático, documentos internos, imagens
   com metadados (nomes de arquivo revelam informações)
3. **Configuração completa exposta**: URLs de bucket, caminhos, ACLs
4. **Upload bloqueado (atualmente)**: Mas ACL 1023 e deniedExtensions vazio indicam
   que upload pode ser ativado a qualquer momento por uma mudança de configuração
5. **Bucket não listável**: Mas objetos individuais são acessíveis se o caminho for conhecido

## Recomendação

1. **Adicionar autenticação** ao endpoint `/ckfinder/connector` (exigir login admin)
2. **Remover permissão pública de leitura** do bucket S3 focus-library
3. **Configurar deniedExtensions** para bloquear upload de executáveis (php, py, js, sh, etc.)
4. **Restringir ACL** no CKFinder para operações read-only (ACL 1 ao invés de 1023)
5. **Implementar CSRF protection** no Laravel para o endpoint CKFinder
6. **Auditar** se algum arquivo sensível está exposto no bucket
