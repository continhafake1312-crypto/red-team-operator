# C-009: CKFinder Reativado - ResourceTypes de Volta com focus-library
**Severidade:** Alta
**Data:** 2026-09-03

## Descrição
O CKFinder Connector em admin.focusconcursos.com.br, que estava com resourceTypes vazio na última verificação (2026-08-26), AGORA ESTÁ DE VOLTA com resourceTypes "Arquivos" e "Imagens" apontando para o bucket S3 focus-library (sa-east-1). Isto indica que houve uma RECONFIGURAÇÃO do ambiente.

## Detalhes

| Parâmetro | Antes (26/08) | Agora (03/09) |
|-----------|---------------|----------------|
| resourceTypes | [] (vazio) | ["Arquivos", "Imagens"] |
| ACL | - | 1023 (Full Control) |
| Hash | - | b68d7c20192e811c / 16b8c883fcc991a6 |
| MaxSize | 268435456 | 268435456 (256 MB) |
| Thumbnails | 150x150, 300x300, 500x500 | Mesmo |
| Allowed Extensions (Arquivos) | - | 7z,aiff,asf,avi,bmp,csv,doc,docx,fla,flv,gif,gz,gzip,jpeg,jpg,mid,mov,mp3,mp4,mpc,mpeg,mpg,ods,odt,pdf,png,ppt,pptx,pxd,qt,ram,rar,rm,rmi,rmvb,rtf,sdc,sitd,swf,sxc,sxw,tar,tgz,tif,tiff,txt,vsd,wav,wma,wmv,xls,xlsx,zip |
