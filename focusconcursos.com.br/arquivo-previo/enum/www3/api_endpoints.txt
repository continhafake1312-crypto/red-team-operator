## Endpoints CONFIRMADOS

### 1. /api/track-resolution (POST)
- Método: POST
- Headers: Content-Type: application/json
- Body: {"resolution": "1920x1080"}
- Response: 204 No Content
- CORS: Access-Control-Allow-Origin: *
- Descoberto em: js_layout-e48e777dbde820a7.js (fetch())
- Uso: Tracking de resolução de tela do usuário
- Teste GET: 405 Method Not Allowed

### 2. /api/track-resolution (GET)
- Response: 405 Method Not Allowed
- Confirma que o endpoint existe mas só aceita POST

### 3. /.well-known/assetlinks.json
- Response: 200, application/json
- Cache-Control: public, max-age=3600
- Rewrite interno: → /api/well-known/assetlinks
- CORS: Access-Control-Allow-Origin: *

### 4. /.well-known/apple-app-site-association
- Response: 200, application/json
- Cache-Control: public, max-age=3600
- Rewrite interno: → /api/well-known/apple-app-site-association

- Descoberto via build manifest (_buildManifest.js)
- Rewrite interno de /favicon.ico → /api/favicon
