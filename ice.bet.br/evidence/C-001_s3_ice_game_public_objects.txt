## Descrição
O bucket S3 "ice-game" (sa-east-1) contém objetos acessíveis publicamente via HTTP GET sem qualquer autenticação. O bucket é usado como CDN para assets estáticos (favicon, logos) da plataforma ICE.

## Reprodução

### Teste 1: GET em objeto conhecido (favicon.png)
```bash
$ curl -sI https://ice-game.s3.sa-east-1.amazonaws.com/favicon.png
HTTP/1.1 200 OK
Content-Type: image/png
Content-Length: 63001
Server: AmazonS3
```

### Teste 2: GET em objeto no subdiretório (logos/icon.png)
```bash
$ curl -sI https://ice-game.s3.sa-east-1.amazonaws.com/logos/icon.png

Content-Type: image/png
Content-Length: 44193

```

### Teste 3: Tentativa de listagem (negada)

## Impacto
🟡 **Médio** — Objetos de branding (logos, favicons) expostos publicamente.
- **Dados sensíveis:** NÃO encontrados (configs, credenciais, backups, dados de usuários)
- **Uso:** CDN de assets estáticos para a plataforma ICE Bet
- **Risco:** Imagens podem ser baixadas por qualquer pessoa, mas não contêm dados sensíveis

## Recomendação
- **Curto prazo:** Revisar a política do bucket para bloquear acesso público se não for necessário para CDN
- **Médio prazo:** Migrar assets para CloudFront com Origin Access Identity (OAI) — o acesso ao S3 deve ser apenas via CloudFront
- **Verificar:** Se o bucket ice-game-dev precisa de assets públicos
