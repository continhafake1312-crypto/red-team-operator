# Subdomain Takeover Assessment — ice.bet.br
# Date: 2026-09-03 UTC
# Operator: cloud specialist

## Methodology
For each subdomain, we checked:
1. DNS A/AAAA/CNAME records
2. HTTP response status code
3. "Dangling CNAME" — CNAME pointing to deprovisioned service
4. "Dead DNS" — subdomain without any DNS record (NXDOMAIN)

## Results

### 🔴 CRITICAL — None Found
No confirmed subdomain takeover candidates.

### 🟡 MEDIUM — Dead DNS (NXDOMAIN, No CNAME)

| Subdomain | DNS Status | CNAME Target | Takeover Possible |
|-----------|-----------|--------------|-------------------|
| proxy-dev.ice.bet.br | ❌ NXDOMAIN | No CNAME record | ❌ No — No CNAME to claim |
| unsubscribe.ice.bet.br | ❌ NXDOMAIN | No CNAME record | ❌ No — No CNAME to claim |
| unsubscribed.ice.bet.br | ❌ NXDOMAIN | No CNAME record | ❌ No — No CNAME to claim |

**Analysis:** These subdomains have NO DNS records at all (NXDOMAIN returns HINFO "RFC8482").
Subdomain takeover via CNAME dangling is NOT possible because there's no CNAME to claim.
These are simply unused/decommissioned subdomains.

**Potential Risk:** If in the future someone adds a CNAME record for these subdomains 
pointing to an external service, they could become takeover candidates. But currently,
there is no attack vector.

**Recommendation:** Monitor these subdomains for any future DNS changes. Re-check 
periodically.

### AWS ELB Endpoints (Potential Risks)
- **grafana/loki**: k8s-monitori-lokigraf-*.elb.amazonaws.com — EKS monitoring
- **popok**: k8s-apps-popoking-*.elb.amazonaws.com — Game server
- These ELBs exist and respond but are blocked by security groups (timeout)
- **Risk:** If security groups are misconfigured, these could be accessible
- **Risk:** ELB DNS names are persistent — if EKS cluster is deleted, ELB might remain dangling
