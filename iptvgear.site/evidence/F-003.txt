## Impacto
1. Versões de plugins expostas permitem CVE targeting
2. Slider Revolution 6.2.22 — múltiplos CVEs (CVE-2024-34444 UNAUTH XSS CVSS 8.8, CVE-2023-47784 Arbitrary File Upload)
3. User "admin" confirmado — alvo para brute force
4. REST API permite reconhecimento do stack completo

## Recomendação
1. Atualizar todos os plugins WordPress
2. Restringir WP REST API para usuários autenticados
3. Implementar rate limiting no /wp-login.php
4. Remover /readme.html, /license.txt expostos
5. Atualizar Slider Revolution para >= 6.7.0
