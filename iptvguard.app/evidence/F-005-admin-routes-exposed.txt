# F-005: Rotas Admin Expostas no JS Bundle do BackOffice

**Severidade**: Média (Exposição de Superfície de Ataque)
**Host**: hq.iptvguard.app (BackOffice)
**Fonte**: JS bundle de 1.5MB
**Data**: 2026-08-22T20:38:00Z

## Descrição
O bundle JavaScript do BackOffice contém TODAS as rotas internas do painel administrativo em texto claro (~60 rotas), incluindo endpoints de gestão de usuários, receita, providers, agendamento TV, push notifications, etc.

## Rotas Expostas (Amostra)

- `/signin` — Login
- `/auth/update-password` — Atualizar senha

### Gestão de Usuários

- `/admin/users` — CRUD usuários
- `/admin/users/stats` — Estatísticas de usuários
- `/admin/users/cleanup-orphans` — Limpar órfãos
- `/early-users` — Early adopters

### Financeiro / Receita

### Providers / Playlists

## Impacto
- **Superfície de ataque completa**: Qualquer atacante conhece todas as funcionalidades admin
- **IDOR candidates**: Endpoints com parâmetros `{id}` são candidatos óbvios
- **Rotas de configuração**: `/admin/providers/*`, `/admin/tv-scheduler/*` indicam funcionalidades críticas
- **Sem ofuscação**: O JS não tem minificação/obfuscação efetiva — rotas em texto claro

## Recomendação
- Implementar lazy-loading de rotas (code splitting)
- Nunca expor todas as rotas no bundle inicial
- Ofuscar nomes de rotas em produção
- Implementar autorização server-side (já existe para admin endpoints)
- Usar dynamic imports para rotas admin
