## Interpretação
WP REST API expõe dados completos sem autenticação:
- Usuários: permite identificar contas admin para brute force direcionado
- Páginas/Páginas: revela estrutura do site, páginas de contato, etc
- Media: Elementor screenshots revelam layout interno, uploads de pagamento
- WooCommerce e Jetpack não estão expostos (retornam 404)

## Impacto
- Identificação de contas admin para ataque de força bruta
- Páginas expostas podem conter informações sensíveis
- Screenshots do Elementor revelam estrutura de design
- Sem exposição de dados financeiros (WooCommerce bloqueado)

## Recomendação
- Restringir acesso público a /wp-json/wp/v2/users/
- Implementar autenticação para endpoints de mídia
- Considerar plugin de segurança WP (restrict REST API)
