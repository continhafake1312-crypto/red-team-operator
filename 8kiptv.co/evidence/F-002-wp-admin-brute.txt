## Testes via wp-login.php (rate limitado)

## Testes via XML-RPC system.multicall (bypass rate limit - SEM BLOQUEIO)
Método: system.multicall com wp.getUsersBlogs
34 senhas × 2 usuários = 68 tentativas em UMA requisição HTTP
Resultado: TODAS retornaram "Incorrect username or password" (faultCode 403)
Senhas testadas: admin, password, admin123, test, test123, 123456, admin1,
admin2025, admin2024, 8kiptv, iptv2024, iptv2025, streaming, support, demo,

## Interpretação
Loginizer rate limiting bloqueia brute force via wp-login.php (>2 tentativas/minuto).
XML-RPC system.multicall BYPASSA completamente o rate limiting - 68 tentativas
em uma única requisição HTTP sem bloqueio.
WordPress XML-RPC é um vetor clássico de brute force que bypassa Loginizer.

## Impacto
- Acesso admin WP por brute force é VIÁVEL via XML-RPC system.multicall
- Precisa de wordlist mais extensa (SecLists/Passwords/)
- Acesso admin daria RCE via theme/plugin editor

## Recomendação
- Desabilitar XML-RPC (add_filter('xmlrpc_enabled', '__return_false'))
- ou usar plugin que limite XML-RPC por IP
- Implementar 2FA no WP Admin
