## Interpretação
A API do Elementor está exposta mas requer autenticação via cookie/nonce do WordPress.
Sem credenciais WP, a maioria dos endpoints retorna 401.
O mapeamento completo de 50+ rotas permite ataque direcionado após obter acesso WP admin.
Settings endpoint retorna 400 em vez de 401 - pode ser explorado com parâmetros válidos.

## Impacto
- Com acesso WP admin: Form Submissions expõe dados de usuários (nomes, emails, IPs, mensagens)
- Template library permite upload/download de templates (potencial RCE)
- Globals expõe configurações de design (cores, tipografia)
- Cache flush (DELETE /cache) permite DoS limitado

## Recomendação
- Bloquear acesso público à API Elementor (restrict /wp-json/elementor/)
- Validar nonces corretamente em todos os endpoints
- Logar tentativas de acesso não autorizado
