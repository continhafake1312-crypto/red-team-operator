# F-007 Zendesk Knowledge Base — Full Access via Playwright Bypass (ALTA)

Alvo: basedeconhecimento.bagy.com.br (Zendesk)
Severidade: Alta
Timestamp: 2026-08-20T15:12:00Z

## Reprodução

Utilizou-se navegador headless (Playwright Chromium) para contornar o Cloudflare
Managed Challenge (JS challenge) e acessar a base de conhecimento Zendesk.

Comando: `playwright.chromium.launch(headless=True)` + navegação para o alvo.

## Interpretação

O Zendesk Help Center está acessível publicamente após bypass do Cloudflare JS challenge
usando navegador headless. Embora o Zendesk seja destinado a clientes da Bagy, o acesso
à documentação da API expõe:

1. **Endpoint completo da API** de integração (mesmo que o base URL seja variável)
2. **Estrutura completa** dos recursos da API (produtos, pedidos, clientes, etc.)
3. **Parâmetros, headers, exemplos** de requisição
4. **Processo de homologação** que pode ser explorado para obter acesso como parceiro
5. **Base de conhecimento interna** com detalhes operacionais da plataforma

## Impacto

- **ALTO**: Concorrentes podem obter detalhes da arquitetura da API
- **MÉDIO**: A documentação facilita ataques direcionados se o endpoint real for descoberto
- **MÉDIO**: O processo de homologação pode ser explorado para obter acesso legítimo como parceiro
- **INFO**: 569 artigos de conhecimento interno expostos publicamente

## Recomendação

1. Revisar permissões do Zendesk — considerar se o conteúdo deve ser público
2. Implementar autenticação no Help Center (exigir login para acessar documentação técnica)
3. Remover informações sensíveis da documentação pública (endpoints, exemplos com credenciais)
4. Considerar Cloudflare Turnstile ou WAF mais restritivo para o Help Center
5. Monitorar logs de acesso ao Zendesk para detectar scraping
