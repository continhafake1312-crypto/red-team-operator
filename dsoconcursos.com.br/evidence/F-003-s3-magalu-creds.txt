## Output / Interpretação
- Credenciais Magalu S3 (`c38cc592... / 3c6df8ef...`) **válidas — não rotacionadas**.
- Acesso a 20 buckets incluindo:
  - `gitlab-backups` → backups do GitLab (CI/CD variables em texto claro = 75 secrets).
  - `postgres-backups` + `postgres-pgbackrest` → dumps do banco de produção (PII).
  - `dso-tfstate-prod` → Terraform state (vaza IPs internos, secrets de infra).
  - `dsoconcursos-nextcloud-drive` / `dsoconcursos-cloudreve-drive` → arquivos de alunos (PII).
  - `dso-devops`, `dso-obs-*` → artefatos de DevOps/observabilidade.
- Bucket `dsoconcursos-prod` retorna AccessDenied (permissão restrita), mas 19 listáveis.

## Impacto
- Acesso a backups completos (GitLab + PostgreSQL) → fonte das credenciais vazadas
  usadas em F-001 (PostgreSQL) e F-002 (JWT). Confirma cadeia de exfiltração.
- Terraform state expõe topologia de infra e secrets de serviços.
- Drives de alunos (Nextcloud/Cloudreve) → PII/documentos.

## Recomendação
- Rotacionar IMEDIATAMENTE as chaves Magalu S3 (access + secret).
- Revisar permissões IAM (ListBucket deve ser restrito a serviços, não a keys genéricas).
- Mover backups/sensitive buckets para conta separada com acesso privado.
- Encriptar backups em repouso com KMS gerenciado por vault.
