# F-MCP-RCE — MCP endpoint com RCE (entry point original ainda vulnerável)

- **Data:** 2026-08-27T14:55Z
- **Severidade:** 🔴 CRÍTICA (RCE em container da rede interna)
- **Impacto:** Execução de código arbitrário no container MCP (172.19.0.3), acesso a rede interna Docker, SSRF para serviços internos, leitura de Redis e LiteLLM internos
- **Origem:** prior-report/reports/02-CADEIA-DE-ATAQUE.md (ETAPA 2) — vetor não corrigido ~5 semanas após relatório anterior

## Vetor
1. `mcp-aws.dsoconcursos.com.br` tem IP real **3.83.108.124** (AWS, fora Cloudflare)
2. Endpoint MCP em `/mcp` requer Bearer (LiteLLM master key `74fe8c6e...`)
3. Tool `DSO-executar_python` executa Python em sandbox
4. **Bypass do sandbox:** `pathlib.Path('/proc/1/environ').read_bytes()` — `pathlib` não está na blacklist (mesmo bug do relatório anterior)
5. **Bypass do SSRF guard:** `urllib.request.urlopen()` não é bloqueado e bypassa o guard do `DSO-http_request` (que limita ports a [80,443])
