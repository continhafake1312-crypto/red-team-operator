# F-006 Supabase Information Disclosure (Table Names via Error Messages)
Alvo: ahfviyykpaljzxcmdyfh.supabase.co (via anon key exposta)
Severidade: Baixa
Timestamp: 2026-08-24T18:10:00Z

## Reprodução
Usando a chave anon exposta no bundle JS, consultas REST ao Supabase retornam mensagens de erro que revelam nomes de tabelas:
- GET /rest/v1/tables → "permission denied for table {table_name}"
- Tabelas descobertas: coupons, orders, accounts, api_keys, profiles, wallets, payments

## Output
```
GET /rest/v1/coupons → {"code":"42501","hint":"GRANT SELECT ON public.coupons TO anon","message":"permission denied for table coupons"}
GET /rest/v1/orders → 401
GET /rest/v1/accounts → 401
GET /rest/v1/api_keys → 401
```

## Interpretação
O Supabase possui RLS (Row Level Security) configurado, impedindo acesso direto pela chave anon. Entretanto, as mensagens de erro expõem os nomes das tabelas do banco de dados.

## Impacto
Atacante obtém informações sobre a estrutura do banco de dados (7 tabelas identificadas).

## Recomendação
Desabilitar mensagens de erro detalhadas no Supabase em produção. Usar um proxy que sanitize respostas de erro.

## Próximo passo
Testar se alguma tabela tem RLS mal configurada permitindo SELECT/INSERT via anon key.
