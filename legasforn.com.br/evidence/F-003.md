# F-003 Rate Limit Ausente/Ineficaz
Alvo: legasforn.com.br (69.46.46.84 via Railway)
Severidade: Média
Timestamp: 2026-08-24T18:00:00Z

## Reprodução
Enviados 60 requests simultâneos (xargs -P10) para /api/v1/wallet com Bearer token válido. Nenhum retornou 429 (Rate Limited).

## Output
```
60 200  <- All 60 requests succeeded
```

## Interpretação
A documentação da API afirma rate limit de 120 req/min por chave, porém o rate limiting não está sendo aplicado efetivamente. 60 requests em ~7.5s (equivalente a ~480 req/min) não ativaram qualquer bloqueio.

## Impacto
Permite ataques de força bruta, scraping massivo e DoS contra endpoints da API sem restrição efetiva.

## Recomendação
Implementar rate limiting no middleware ou no gateway (Railway/Hikari) por token de API e por IP.
