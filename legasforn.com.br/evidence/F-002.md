## Impacto
- **Médio**: Dados de produtos, preços, descrições e metadados expostos em formato estruturado
- **Baixo**: Não expõem dados de usuários ou tokens de autenticação
- **Info**: Revela a estrutura completa de rotas da aplicação, facilitando enumeração

## Recomendação
- Implementar verificação de autenticação nos endpoints RSC que retornam dados sensíveis
- Considerar usar Next.js middleware para bloquear acesso não-autenticado a `/_next/data/`
- Build ID deve ser rotacionado entre deploys
