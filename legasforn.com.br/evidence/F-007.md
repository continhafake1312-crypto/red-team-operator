# F-007 CORS Misconfiguration
Alvo: legasforn.com.br (69.46.46.84 via Railway)
Severidade: Info
Timestamp: 2026-08-24T18:10:00Z

## Reprodução
Requisição com Origin: https://evil.com não retorna cabeçalhos Access-Control-Allow-Origin.

## Output
```
$ curl -s -D - 'https://legasforn.com.br/api/v1/games' -H 'Origin: https://evil.com' | grep -i access-control
(empty - no CORS headers returned)
```

## Interpretação
A API não implementa CORS. Isso significa que não é possível fazer requisições cross-origin de navegadores de terceiros. Não é uma vulnerabilidade, mas limita integrações legítimas.

## Impacto
Baixo - a API retorna apenas JSON, sem CORS configurado. Ataques CSRF via API não são possíveis sem CORS.

## Recomendação
Configurar CORS apropriadamente se houver necessidade de integrações client-side de terceiros.
