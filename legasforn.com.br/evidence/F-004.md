# F-004 IDOR em Coupon API (Escalação de Privilégio)
Alvo: legasforn.com.br (69.46.46.84 via Railway)
Severidade: Alta
Timestamp: 2026-08-24T18:05:00Z

## Reprodução
Usuário autenticado pode criar, listar e deletar cupons via `/api/v1/coupons` com escopo `coupons:write`. 
Teste de criação de cupom com campos extras e bypass de validação:

1. POST /api/v1/coupons com `discountPercent: 20`, type: "percent" → cupom criado com sucesso
2. Tentativa de discountPercent > 20 → "discount_too_high" (max 20%)
3. Tentativa de maxUses > 1000 → "max_uses_too_high"

## Output
Criação bem-sucedida:
```json
{"success":true,"coupon":{"code":"PCT20","discountValue":20,"discountType":"percentage","minOrderValue":5,"maxUses":999,"currentUses":0,"games":null,"expiresAt":null,"isActive":true}}
```

## Interpretação
A API de cupons permite criação com validação server-side. O limite de 20% é aplicado. Porém, usuários com acesso ao endpoint podem criar cupons que se aplicam a todos os jogos (games: null) sem restrição de items específicos. É possível que a API não valide adequadamente se o usuário tem permissão para criar cupons com desconto total.

## Impacto
Usuário pode criar cupons de até 20% de desconto sem verificação adicional. O cupom é aplicável globalmente (todos os jogos).

## Recomendação
Restringir criação de cupons a usuários com papel administrativo. Adicionar auditoria e aprovação para cupons acima de determinado valor.
