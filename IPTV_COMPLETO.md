## 7️⃣ VERIFICAÇÃO E TESTES

### ✅ COMO TESTAR OS LINKS

**Método 1: VLC Media Player**
1. Baixe e instale o VLC
2. Clique em `Mídia > Abrir Fluxo de Rede`
3. Cole o link `.m3u8` ou `.m3u`
4. Clique em `Reproduzir`

**Método 2: Teste com curl**
```bash
curl -s -o /dev/null -w "%{http_code} %{time_total}s" "https://URL_DO_STREAM"
```

**Método 3: ffprobe/ffmpeg**
```bash
ffprobe -v quiet -print_format json -show_streams "URL_DO_STREAM"
```
