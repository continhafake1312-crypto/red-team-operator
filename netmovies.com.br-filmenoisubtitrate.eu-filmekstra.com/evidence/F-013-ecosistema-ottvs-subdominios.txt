## Detalhes da API
- **84 endpoints REST** mapeados via appconfig.json
- **Versões**: /v1/android, /v1/ios, /v1/roku, /v1/browser
- **Server**: Kestrel (ASP.NET Core) — confirmado via header de resposta
- **Auth**: AuthenticationTicket (string) no body POST — secret vazado (F-005)
- **Backend**: TrueTech Service API (namespace `Truetech.Service.API`)

## Interpretação
A NetMovies utiliza uma plataforma OTT white-label chamada "OTTvs" (OTT Video System?) hospedada em `ottvs.com.br`. O ecossistema inclui API principal, heartbeat tracking, servidor de licenças DRM (Widevine/PlayReady/FairPlay), CDN de imagens, asset streaming server, e Azure Blob para configs.

## Impacto
- **Superfície de ataque expandida** — múltiplos subdomínios podem ter vulnerabilidades independentes
- **DRM bypass** — se os endpoints de licença aceitarem requests sem validação, conteúdo pode ser descriptografado
- **Heartbeat tracking** — pode expor dados de visualização dos usuários
- **Asset server** — streaming sem autenticação via token (URLs retornam 404 sem token)

## Recomendação
1. Revisar segurança de TODOS os subdomínios ottvs.com.br
2. Implementar autenticação no License Server
3. Restringir acesso ao asset-01.ottvs.com.br por IP/token
4. Avaliar necessidade de expor heartbeatservice publicamente
5. Auditoria de segurança em toda plataforma OTTvs
