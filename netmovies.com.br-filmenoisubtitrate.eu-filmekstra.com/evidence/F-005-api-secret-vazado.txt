# F-005 API Secret Vazado em JS Bundle

Alvo: netmovies.com.br (JS bundle público)
Severidade: CRÍTICA
Timestamp: 2026-08-20T03:35:00Z

## Reprodução
```
Arquivo: /_next/static/chunks/pages/_app-*.js
Secret encontrado: "secret: \"netmovies@netmovies:a1c2af@#$\""

Validação:
$ curl -s -X POST https://netmovies-service.ottvs.com.br/v1/android/GetCountries \
  -H "Content-Type: application/json" \
  -d '{"AuthenticationTicket":"netmovies@netmovies:a1c2af@#$"}' | jq .
{
  "Result": 0,
  "CountryList": [...]
}
```

## Interpretação
O AuthenticationTicket (secret) da API REST do backend está hardcoded no bundle
JavaScript do Next.js, servido publicamente sem autenticação. Este secret permite
chamar QUALQUER endpoint da API que aceite AuthenticationTicket como forma de
autenticação, incluindo:

- /Login (login como qualquer usuário — se combinar com senha)
- /GetUserInfo (PII de qualquer usuário)
- /GetMediaUrl (streams HLS/DASH sem assinatura)
- /AddFullUser (criar contas)
- /UpdateUser (modificar dados de usuários)
- /GetProfiles (perfis de usuários)
- /GetSubscriptions (dados de assinatura/pagamento)
- /SubscriptionCancel (cancelar assinaturas)
- /SendSMSWithValidationCode (enviar SMS em nome da plataforma)

## Impacto
- **Acesso total à API** sem autenticação de usuário
- **Exposição completa do catálogo** de mídia, usuários e dados financeiros
- **Capacidade de enumerar emails** via VerifyUserExist
- **Acesso a streams de mídia** sem assinatura (IDOR via GetMediaUrl)
- **Manipulação de contas** (criar, modificar, deletar)
- **Risco de engenharia social** usando dados extraídos

## Recomendação
1. **IMEDIATO**: Remover secret do JS bundle. Usar variável de ambiente server-side
2. Implementar autenticação por token JWT com expiry para chamadas de API
3. Rotacionar o secret comprometido imediatamente
4. Revisar todos os bundles JS para outros secrets hardcoded
5. Implementar rate limiting e validação de origem (CORS) na API

tentar login com senhas comuns (creds-stuffing).
