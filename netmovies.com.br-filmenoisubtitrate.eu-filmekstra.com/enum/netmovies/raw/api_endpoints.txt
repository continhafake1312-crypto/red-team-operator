# API Endpoints - netmovies-service.ottvs.com.br

## Base URLs
API Base: https://netmovies-service.ottvs.com.br
Versões: v1/android, v1/ios, v1/roku, v1/browser
Server: Kestrel (ASP.NET Core)
Autenticação: AuthenticationTicket via POST body
Secret vazado: netmovies@netmovies:a1c2af@#$

## Endpoints confirmados (60+) - via appconfig_{tv,roku,ios}.json
