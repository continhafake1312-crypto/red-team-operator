# /api/admin/ Fuzz — apex + api hosts
# Fase 5. Objetivo: descobrir sub-rotas admin.

============================================================
## Conclusão principal: /api/admin/* é CATCH-ALL 401
============================================================
Em AMBOS os hosts (apex: 47B, api: 42B), QUALQUER sub-path de /api/admin/*
retorna 401 "Não autenticado." com corpo idêntico — inclusive paths inexistentes
e valores numéricos.

=> O middleware de admin-auth executa ANTES do roteamento de sub-rotas.
=> Impossível enumerar quais sub-rotas admin existem via fuzzing sem credencial admin.
=> Estratégia: obter cred admin (brute force login api sem Turnstile, ou privesc
   via mass-assignment de user.tipo) e então enumerar as rotas reais.
