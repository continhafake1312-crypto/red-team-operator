2. SUMÁRIO EXECUTIVO
───────────────────────────────────────────────────────────────────────────────

  O pentest contra andresan.com.br revelou 18 vulnerabilidades, sendo 2
  CRÍTICAS, 7 Altas, 6 Médias, 2 Baixas e 1 Não-Aplicável.

  DESTAQUES:
  • F-013 (CRÍTICA):  Painel admin vaza TODOS os segredos de gateway/pagamento
    (Stripe webhook secret, RD Station, edustore API) via Inertia props —
    qualquer visitante anônimo recebe chaves de API em texto claro.
  • F-014 (CRÍTICA):  O secret vazado do edustore é a shared secret do servidor
    BigBlueButton (meet.edustore.online). Acesso TOTAL: 68 gravações de aulas
    de múltiplas empresas (~13GB), criar reuniões, entrar como moderador.
    Multi-tenant comprometido — várias empresas expostas.
  • F-015 (Alta):     API pública sem auth: /api/v1/courses (2MB) e
    /api/v1/teachers (38MB, 63 professores com user_ids).
  • F-018 (Alta):     Postback de pagamento Asaas aceita POST sem validação de
    token — potencial para forjar confirmações de pagamento.
  • F-005 (Alta):     WordPress 4.8.30 desatualizado no blog (bloqueado por
    Cloudflare — pendente bypass).
  • F-001 a F-004:    IP real exposto, 2 painéis admin, uploads legíveis.

  CONSEGUIMOS ACESSO A:
  1. BigBlueButton (meet.edustore.online) — API total (68 gravações, criar/entrar
     reuniões como moderador)
  2. Stripe webhook secret + credenciais de gateway — acesso indireto a sistemas
     financeiros
  3. RD Station CRM — code+secret para operar a conta de CRM
  4. API pública de cursos e professores
  5. E-mails internos + dados financeiros da empresa

  NÃO CONSEGUIMOS (ainda):
  • Login admin no painel (cred-stuffing falhou, SQLi sem diferença visível)
  • Laravel Ignition RCE (debug mode desligado)
  • WordPress / areadoaluno (Cloudflare bloqueia — pendente bypass)
