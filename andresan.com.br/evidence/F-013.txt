# F-013 — Credenciais de gateway e segredos expostos via Inertia page props (não-autenticado)

| Campo | Valor |
|-------|-------|
| **Severidade** | CRÍTICA |

| **Endpoint** | `GET /auth` (e `GET /entrar`) |
| **Autenticação** | Nenhuma (anônimo) |
| **CWE** | CWE-200 (Exposição de Informação a Atores Não-Autorizados) / CWE-522 (Credenciais Insuficientemente Protegidas) |
| **Plataforma** | Laravel + Inertia.js (edustore LMS SaaS), componente `Auth/SigninMatrix` |
| **Status** | Confirmado |

## Descrição

O endpoint público de autenticação (`/auth`) da plataforma edustore retorna, no
atributo `data-page="..."` do elemento `<div id="app">` (props do Inertia
compartilhadas com qualquer visitante), todo o conjunto de configurações de
plugins/gateways de pagamento **com segredos em texto claro**. Qualquer visitante
anônimo recebe, sem login, chaves de API, segredos de webhook e credenciais de
integração de gateways (Stripe, Asaas/Pagar.me, RD Station).

## Reprodução

```bash
# 1. Requisição anônima ao /auth (Laravel+Inertia)
curl -sk -H "Host: painel.andresan.com.br" https://187.127.31.48/auth \
  -o /tmp/auth.html

# 2. Extrair props do Inertia (JSON no atributo data-page)
python3 -c '
import re,html,json
d=open("/tmp/auth.html",encoding="utf-8",errors="replace").read()
m=re.search(r"data-page=\"([^\"]*)\"",d)
j=json.loads(html.unescape(m.group(1)))
print(json.dumps(j["props"]["active_plugins"],ensure_ascii=False,indent=2))
'
```

## Impacto

1. **Acesso a sistemas financeiros externos**: segredo de webhook Stripe e chaves
   de API de gateways (Asaas/Pagar.me) permitem forjar confirmações de pagamento,
   consultar transações, manipular status de cobrança — impacto financeiro direto.
2. **Acesso a CRM (RD Station)**: code+secret permitem operar a conta de CRM,
   vazar leads/dados de clientes.
3. **Vetor de acesso indireto à plataforma**: e-mails internos vazados são ammo
   de cred-stuffing contra `/login` (rate-limitado em ~5/min, mas os endereços
   internos agora são conhecidos).
4. **PII/segredo de negócio**: CNPJ, contrato de LMS, margens, dados de
  contabilidade expostos.

## Recomendação

- NÃO compartilhar `active_plugins` (com `config_value` de segredos) nas props
  Inertia de páginas públicas. Criar props separadas só com metadados
  não-sensíveis para a view de login; servir configs de gateway somente após
  autenticação e com autorização por role.
- Rotacionar imediatamente: segredo de webhook Stripe, chaves de API dos
  gateways (Asaas/Pagar.me), credenciais RD Station.
- Adicionar policy de autorização no controller que monta as props de login
  (ocultar `active_plugins`, `gateways`, `company`, `ai_quota_status`).
