## Description
The WordPress media library of the DFG course portal exposes 666 media items publicly (no auth)
via `/wp-json/wp/v2/media`, including the `media_details.image_meta` (curated EXIF subset) AND
directly downloadable original `-scaled.jpeg` files in `/wp-content/uploads/` that PRESERVE FULL
EXIF metadata, including **GPS coordinates precise to ~11 metres**, capture timestamp, camera
make/model, and software version. WordPress was configured with Imagick (or without EXIF
stripping) so the resized `-scaled` images retain the original GPS EXIF.

The GPS-tagged photos are real photos taken by course participants/instructors on iPhones
(iPhone 11, iPhone 13, iPhone XS) and uploaded to the portal. Reverse-geocoding the GPS
coordinates resolves to specific neighbourhoods/cities in Brazil, deanonymizing the physical
location (home/clinic/studio) of identifiable individuals whose full names are simultaneously
exposed via media slugs/titles (e.g. "Dr. Vitor Maciel", "Dr. Francisco Geovane") and via the
WP username enumeration (F-W5). This is a privacy / LGPD compliance issue: precise geolocation
of data subjects, unauthenticated, publicly reachable.

## Impact
- Confidentiality (PII): precise physical location (~11 m) of identifiable real people
  (course students/instructors), unauthenticated, publicly downloadable. Enables stalking,
  physical targeting, deanonymization. Under Brazil's LGPD this is unauthorized exposure of
  personal/sensitive location data of data subjects.
- Combined with F-W5 (2000+ usernames) and the name-bearing media slugs, an attacker can link
  a real name → WP account → exact location where they took a course photo.
- The exposure of 9+ iPhone personal photos (with timestamps in 2024-2025) indicates the
  instructors/students upload personal photos that retain full EXIF — a recurring, systemic issue.

## Recommendation
- Strip ALL EXIF/metadata from uploaded images on ingest: configure WordPress/Imagick to remove
  EXIF (`wp_strip_image_meta` / plugin like "Image Metadata Cruncher" / "Strip EXIF"), or convert
  uploads through a pipeline that drops GPS. Do NOT serve original `-scaled` files with EXIF.
- Restrict the media library: do not expose `/wp-json/wp/v2/media` and `/wp-content/uploads/`
  unauthenticated for non-public assets. Mark course/instructor media as private/attachment-to-
  protected-post. (WooCommerce/Sensei/Tutor LMS can gate media to enrolled users.)
- Remove/replace the GPS-tagged photos already exposed (they may have been cached by search
  engines/CDNs — request removal). Re-process existing uploads to strip EXIF.
- Audit which user accounts (F-W5 ids) uploaded PII media and notify affected data subjects per
  LGPD art. 48 (breach notification to ANPD if applicable).
- Disable open user registration (spam accounts present — see F-W5).
