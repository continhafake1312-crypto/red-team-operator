================================================================================
F-012: ADMIN PANEL — Password-based authentication (non-OTP)
================================================================================
Severidade: 🔴 CRÍTICA — Acesso ao painel admin sem OTP
Status:    ✅ Confirmado
Fase:      exploit
Data:      2026-08-26

================================================================================
DESCRIÇÃO
================================================================================
O portal marcas.keoto.com possui DOIS sistemas de login separados:

1. /login          → OTP de 6 dígitos (via email/WhatsApp)
2. /admin/login    → Email + Senha (NextAuth credentials provider)

O painel admin usa o placeholder "admin@keotomarcas.com" como email
sugerido, indicando o formato de email administrativo.

================================================================================
DETALHES TÉCNICOS
================================================================================

Rota:              /admin/login
Título:            "Painel Administrativo"
Formulário:        Email + Password
Provider:          NextAuth "credentials" (único provider)
Endpoint:          POST /api/auth/callback/credentials
Campos:            csrfToken, email, password
CSRF:              Obrigatório (obtido via GET /api/auth/csrf)
Rate limit:        NÃO OBSERVADO — 10 tentativas sucessivas sem 429

================================================================================
COMPORTAMENTO
================================================================================

Admin login bem-sucedido:
  Location: /admin/dashboard (presumido)

Admin login falho (credenciais inválidas):
  Location: /admin/login?error=CredentialsSignin&code=credentials

Admin login sem CSRF:
  Location: /admin/login?error=MissingCSRF

================================================================================
ENUMERAÇÃO DE EMAILS ADMIN
================================================================================

Testados: admin@keotomarcas.com, admin@keoto.com, admin@keoto.com.br,
          suporte@keotomarcas.com, contato@keotomarcas.com

Resposta: TODOS retornam CredentialsSignin — sem diferença entre
email existente e inexistente (proteção contra enumeration).

================================================================================
CREDENCIAIS TESTADAS

================================================================================
IMPACTO
================================================================================
Se um atacante obtiver ou adivinhar credenciais de admin, ganha acesso
total ao painel administrativo — com acesso a:
  - Gestão de campanhas e clips
  - Configurações de pagamento
  - Dados de marcas e usuários
  - Possível acesso a funcionalidades de exportação/dados

A AUSÊNCIA de rate limiting no endpoint de credentials callback torna
viável ataque de força bruta com wordlist maior.
