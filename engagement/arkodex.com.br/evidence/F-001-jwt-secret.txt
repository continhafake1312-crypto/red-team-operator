# F-001 JWT_SECRET vazado no GitHub
Alvo: arkodexx/url-shortener (GitHub)
Severidade: Crítica
Timestamp: 2026-08-26T00:00:00Z

## Resumo
O arquivo .env foi commitado no repositório público arkodexx/url-shortener
contendo JWT_SECRET e SECRET. Mesmo após "security updates" remover o SECRET,
ambos permanecem acessíveis via git history.

## Reprodução
git clone https://github.com/arkodexx/url-shortener
cd url-shortener
cat .env
# JWT_SECRET=f8431e8ab12c6b485a4c4fe82aad4955cde255b725a4919a68f8329abe49757b7b52463d2c5e64edf92b003c97780d094eccc87e8f5ddc13b3de1b99ebd14424

git show fb42026:.env
# SECRET=2e0d34c8eaadb53417fd960599d3286f875da7e76a00c594275734f01028ae63
# JWT_SECRET=f8431e8ab12c6b485a4c4fe82aad4955cde255b725a4919a68f8329abe49757b7b52463d2c5e64edf92b003c97780d094eccc87e8f5ddc13b3de1b99ebd14424

## Impacto
Qualquer pessoa pode forjar JWTs para o url-shortener. Se mesmo secret for usado
no Discord bot ArkodeX Pro ou API principal (arkodex.com.br), permite acesso total.

## Recomendação
1. Rotacionar IMMEDIATAMENTE o JWT_SECRET
2. Assumir que o SECRET está comprometido e rotacionar também
3. Remover .env do git history (BFR) e adicionar ao .gitignore
4. Verificar se mesmo secret é usado em outros serviços
