---- 7. Análise de risco ----
Exposição: imagens de marca/logos de canais (media/brand/*) acessíveis se path conhecido.
Paths são vazados via CMS API pública (/v1/brand/{id}) → enumerar catálogo completo
(logos, thumbnails de canal) é possível sem auth. Não há dados sensíveis confirmados
no container 'media' (apenas assets de branding). Sem listagem → sem dump completo.
Risco principal: leak de catálogo de canais + exposure de assets (baixo impacto
financeiro/dados, mas confirma má configuração de acesso público a storage de mídia).

---- 8. Recomendação ----
Migrar container 'media' para private access + servir via CDN com SAS temporária ou
tokens assinados. Não depender de obscurity de path (paths vazam via CMS API).
Manter CORS desabilitado (já está). Confirmar que não há container de backups/logs/
config com mesmo padrão (auditar via portal Azure com credenciais da conta).

---- 9. OPSEC ----
Requisições via proxychains4 + Tor. Canário PUT não persistiu (404). Nenhum artefato
existente foi lido além de blobs de branding (imagens). Nenhuma modificação realizada.
