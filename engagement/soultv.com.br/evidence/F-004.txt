## Sumário
O servidor Pure-FTPd [privsep][TLS] em video02:21 permite login anônimo com qualquer senha ("Any password will work"). O diretório root do FTP é vazio (apenas . e ..) e chrootado — não há acesso a diretórios do sistema, arquivos de configuração do Wowza, midias ou logs.

## Teste de escrita
Upload de arquivo canário (nome único):
```
STOR test_XXXXXXXX_canary.txt
550 Anonymous users may not overwrite existing files
```
FTP não é writável — não é possível upload de conteúdo malicioso.

## SITE commands disponíveis
- ALIAS, CHMOD, IDLE, UTIME (apenas CHMOD funcional, demais sem argumento)
- SITE EXEC: não disponível
- Não é possível criar diretórios (SITE MKDIR desconhecido)

## Interpretação
O FTP anônimo existe mas é uma instalação mínima/chrootada puramente para recebimento de mídia/streaming (provavelmente usado por terceiros/publishers para upload de conteúdo via usuários FTP reais, não anonymous). O anonymous tem acesso apenas a um diretório vazio e sem permissão de escrita.

## Impacto
- **Baixo**: não há dados acessíveis, não há escrita possível, não há privesc via FTP.
- A existência de login anônimo em si é uma falha de hardening (pode ser abusada para storage abuse se config mudar, ou para footprint de que o servidor existe).
