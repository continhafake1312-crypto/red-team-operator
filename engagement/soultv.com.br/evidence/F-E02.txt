# Evidence F-E02 — Unauth IDOR on cms.soultv.com.br /v1 leaking premium video catalog + Azure Blob direct URLs

> Specialist: `enum` | Phase 5 | Date: 2026-08-27 | CVSS est: 7.5 (HIGH) — extends recon C-002

## Target
- Host: `https://cms.soultv.com.br/v1` (Cloudflare-fronted) — backend = **Django REST Framework** (error strings "Authentication credentials were not provided.", "Invalid input.")
- Endpoint: `GET /v1/brand/{id}/videos` — **no authentication required**

## Vulnerability
The endpoint `GET /v1/brand/{id}/videos` returns the full video catalog (premium content) for a channel given its numeric `id`, with **no authentication**. Each entry leaks the **Azure Blob direct download URL** (`stsoultvbrs.blob.core.windows.net/media/channel_videos/<file>.mp4`), which is then directly downloadable **without auth** (HTTP 200). This is a BOLA/IDOR exposing the entire premium VOD catalog and bypassing any paywall/subscription.

## Impact
- **Full premium VOD catalog enumeration** without auth (IDOR over `brand/{id}`).
- **Direct Azure Blob download** of every premium movie/show (paywall bypass, content theft). The blob container `media` paths are revealed by the API → expands cloud finding C-002 from "individual blob read" to "full catalog leak + mass download".
- Brand IDs 1..N enumerate all channels (recon already confirmed 200+ IDs in `/v1/brand/{id}`).

(`account/password/reset` route extracted from pay.soultv JS chunk.)
