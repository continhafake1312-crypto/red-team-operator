# F-002 FTP Server (ProFTPD) Publicly Exposed
Alvo: 186.194.52.218:21 (painelrevenda.vip via Tor)
Severidade: Alta
Timestamp: 2026-09-03T05:17:00Z

## Reprodução
```bash
$ proxychains4 nmap -sV --script ftp-* -p 21 186.194.52.218 -Pn
```
Confirmed ProFTPD on port 21.

```bash
$ proxychains4 ftp -inv 186.194.52.218
Connected to 186.194.52.218.
220 ProFTPD Server ready.
331 Password required for anonymous
530 Login incorrect.
Login failed.
```

### Anonymous Login: ❌ FAILED
- ProFTPD requires password for anonymous user

### Default Credentials Tested (all failed):
- ftp:ftp, admin:admin, painel:painel, elite:elite
- revenda:revenda, test:test, user:pass, anonymous:anonymous

### Known ProFTPD CVEs:
- CVE-2023-5171: mod_sftp (requires sftp module enabled)
- CVE-2019-18217: mod_sftp auth bypass (requires sftp)
- CVE-2015-3306: cp command RCE (ProFTPD <= 1.3.5) - versão exata desconhecida
- CVE-2013-4359: mod_sql_passwd SQL injection

## Interpretação
O servidor FTP ProFTPD está exposto publicamente. Embora o login anônimo esteja desabilitado, a simples exposição de um servidor FTP de produção na internet expande a superfície de ataque. Se a versão do ProFTPD for antiga, pode ser vulnerável a RCE (CVE-2015-3306).

## Impacto
- Acesso ao sistema de arquivos do servidor web se credenciais forem obtidas
- Upload de webshells ou arquivos maliciosos
- Exfiltração de dados do servidor
- Potencial RCE se versão vulnerável

## Recomendação
1. Restringir acesso FTP apenas a IPs internos ou via VPN
2. Usar SFTP/SCP em vez de FTP tradicional
3. Desabilitar anonymous login (já desabilitado ✓)
4. Manter ProFTPD atualizado
5. Implementar fail2ban para proteção contra força bruta
