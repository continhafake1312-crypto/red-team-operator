# F-101 JWT Public Key Exposed
Alvo: ifes25-semproxy.selecao.net.br (64.31.24.186)
Severidade: Alta
Timestamp: 2026-08-25T17:42:00Z

## Descrição
O endpoint /.well-known/jwks.json expõe a chave pública RSA (RS256) usada para assinatura de tokens JWT. Isso permite ataques offline como alg:none, HMAC key confusion, e kid injection, caso um endpoint JWT protegido seja encontrado.

## Reprodução
```bash
curl -sk https://ifes25-semproxy.selecao.net.br/.well-known/jwks.json
```

## Ataques Possíveis
1. **alg:none** - JWT com algoritmo none (sem assinatura)
2. **HMAC Key Confusion** - HS256 usando chave pública como segredo
3. **kid Injection** - Path traversal/LFI via campo kid
4. **kid SQLi** - Se backend consulta DB pelo kid

## Status
Nenhum endpoint protegido por JWT Bearer token foi encontrado (endpoints /admin/api/me, /api/me retornam 404). O JWT pode ser usado internamente na sessão Laravel.

## Impacto
Exposição de chave pública permite preparação de ataques para quando um endpoint JWT for descoberto. Risco atual: potencial.

## Recomendação
Remover endpoint /.well-known/jwks.json do acesso público ou implementar rate limiting e monitoramento.
