# F-107 Outdated Libraries
Alvo: ifes25-semproxy.selecao.net.br (64.31.24.186)
Severidade: Média
Timestamp: 2026-08-25T18:00:00Z

## Descrição
Bibliotecas desatualizadas identificadas nas páginas:

1. **jQuery 2.1.3** (Janeiro 2014) - Múltiplos CVEs conhecidos
2. **Summernote 0.8.18** (v0.8.18 identificado no app.css) - WYSIWYG editor
3. **jQuery UI 1.11.2** (Novembro 2014) - Múltiplos CVEs

## Reprodução
Identificado via:
```html
<script src="//static-cdn.selecao.net.br/static/js/jquery-2.1.3.min.js"></script>
<script src="//static-cdn.selecao.net.br/static/js/jquery-ui-1.11.2.custom/jquery-ui.js"></script>
```

Summernote v0.8.18 identificado em app.css:
```
/*!
 * 
 * Super simple wysiwyg editor v0.8.18
 * https://summernote.org
 * 
 */
```

## CVEs Conhecidos
- jQuery 2.1.3: CVE-2015-9251, CVE-2019-11358, CVE-2020-11023
- jQuery UI 1.11.2: CVE-2016-7103, CVE-2021-41183, CVE-2021-41184
- Summernote 0.8.18: CVE-2024-0455 (XSS), CVE-2024-0456

## Impacto
Vulnerabilidades XSS conhecidas podem ser exploradas contra usuários administradores que utilizam o editor Summernote, potencialmente levando a sequestro de sessão.

## Recomendação
Atualizar todas as bibliotecas para as versões mais recentes.
