F-018: Painel Admin — NÃO ENCONTRADO
================================================================
Severidade: INFORMATIVO
Host: https://www.g7juridico.com.br
Data: 04/09/2026
Classificação OWASP: A1 (Broken Access Control)

DESCRIÇÃO
-----------
Varredura exaustiva de paths comuns de admin no www.g7juridico.com.br
e www.g7juridico.com.br/producao/, com e sem sessão válida.

Nenhum painel admin foi encontrado. Todos os paths testados retornam:
- 404 (Not Found) — path inexistente
- 301/302 (Redirect) — redirecionamento para páginas públicas

→ Todos não respondem ou retornam 000 (DNS/timeout)

CONCLUSÃO
----------
O painel admin pode estar:
1. Em um subdomínio não descoberto (DNS enumeration adicional necessária)
2. Acessível apenas via n8n.g7juridico.com.br (n8n workflow automation)
3. Em um path com hash/ID (ex: /producao/area-do-aluno/?admin=1)
4. Ou não existe separadamente — o admin pode ser a própria área do aluno
   com níveis de permissão diferentes

RECOMENDAÇÃO
-------------
1. Fazer enumeração DNS de subdomínios mais agressiva (wordlist de 1000+)
2. Tentar escalar privilégio na área do aluno para encontrar opções admin
3. Explorar n8n (F-011 a F-018) para obter acesso indireto
4. Verificar se o cookie "aluno" pode ser manipulado para acesso admin
