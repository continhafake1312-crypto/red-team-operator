CVE-2026-72533 (HIGH - CVSS 8.8)
  Descrição: Authentication bypass via non-canonical URL normalization.
  Portainer CE through 2.44.0 allows authenticated low-privileged users to 
  bypass Docker proxy authorization checks. The proxy endpoint fails to 
  normalize request paths before applying access controls.
  Vector: AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H
  Pré-condição: REQUER USUÁRIO AUTENTICADO com privilégios mínimos
  PoC disponível: Não encontrado publicamente
  Prioridade: ALTA (após obter credenciais)

CVE-2026-33590 (CVSS N/A - severity não atribuída)
  Descrição: Insecure default settings of Portainer CE grant regular (non-admin) 
  users privileges that allow host filesystem access and host-level code execution.
  An authenticated non-administrative user with endpoint access can exploit these
  settings to read host files or obtain root equivalent access on the host.
  Pré-condição: REQUER USUÁRIO AUTENTICADO não-admin
  Prioridade: MÉDIA (após obter credenciais)
