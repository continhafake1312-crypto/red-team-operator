ChaCha20-Poly1305 support:  true
CBC-EtM support:            false
Strict key exchange:         true

VERDICT: NOT VULNERABLE
------------------------
OpenSSH 8.9p1 includes the strict key exchange countermeasure
for the Terrapin attack. Both peers must support strict kex for
protection. Since our client (OpenSSH 9.6p1) also supports it,
the connection is fully protected.

While ChaCha20-Poly1305 cipher is available (which is a prerequisite
for the attack), the strict key exchange mitigation prevents the
sequence number truncation required for Terrapin exploitation.
