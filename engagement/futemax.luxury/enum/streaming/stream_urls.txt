## API Endpoints (reidosembeds.online)
| Endpoint | Descrição |
|----------|-----------|
| GET /api/channels | Lista todos os canais |
| GET /api/channels/{slug} | Canal por ID |
| GET /api/channels/categories | Lista categorias |
| GET /api/channels?category={cat} | Filtra por categoria |
| GET /api/eventos | Lista eventos |
| GET /api/eventos/{slug} | Evento específico |
| GET /api/eventos/categories | Categorias de eventos |
| GET /api/eventos?category={cat}&status=live | Filtra eventos |
| GET /api/pesquisa?q={query} | Pesquisa global |
| GET /api/guia | Guia XMLTV |
