# Player JS Analysis — Canais Play Theme (canaisplay-theme)

## Player Principal (futemax.luxury/?channel=NOME)

### Arquivo: embutido inline no HTML da página
**Função:** `loadPlayer(url)` — Linha 3072-3133 do channel_globo.html

### Funcionamento:
1. Usuário clica em play ou seleciona stream option
2. JS pega o `data-url` do `<button class="stream-option" data-url="...">`
3. Cria novo `<iframe id="channel-iframe">` com `src = data-url`
4. Mostra loading overlay com barra de progresso simulada
5. Quando iframe carrega (`onload`), esconde loading e mostra player
6. Múltiplas opções de stream podem existir (troca via `e.target.dataset.url`)

### Stream Options:
```html
<div class="stream-options">
    <button class="stream-option" data-url="https://v3.rdse.site/globosp">
</div>
```

### Player UI:
- Loading overlay com "CARREGANDO..."
- Barra de progresso animada
- Botão fullscreen
- Botão de reload
- Botão copy link (compartilhar)
- Botão share (navigator.share)

### Player Container:
```html
<div class="channel-player-section">
    <div class="channel-player-container">
        <div class="channel-player">
            <div class="video-player">
                <div class="loading-overlay">...</div>
                <div class="player-overlay">
                    <div class="player-controls">
                        <button class="fullscreen-button">...</button>
                    </div>
                </div>
                <iframe id="channel-iframe" style="display:none" ...></iframe>
            </div>
        </div>
    </div>
</div>
```

## Camada 2: v3.rdse.site/{slug} (Rei dos Embeds)

### Funcionamento:
1. Página HTML com meta refresh/JS redirect
2. Obfuscação JS pesada (código ofuscado com strings hex)
3. Cria iframe apontando para v1.rdse.lat/__play/{slug}
4. Gera JWT tokens `pt` e `pc` dinamicamente via JS
5. Envia stats beacons para edge.azureedgeglobalfastlycloudfrontondigitaloceanstackpathcdn.buzz

### Stats Tracking:
```javascript
endpoint = "https://edge.azureedgeglobalfastlycloudfrontondigitaloceanstackpathcdn.buzz/internal-stats-lite/p.php"
// Parâmetros: source, domain_host, page_url, referrer_url, client_id, tab_id, instance_id
// Ping a cada 20-25s: enter, ping, leave, close, unload
```

## Camada 3: v1.rdse.lat (Backend Video)

### Funcionamento:
1. Recebe requisição em /__play/{slug}?pt=JWT&pc=JWT
2. Valida ambos os tokens (HMAC-SHA256)
3. Se válido: serve página HTML com iframe para o M3U8 real
4. Se inválido/expired: HTTP 403 "Invalid page token"
