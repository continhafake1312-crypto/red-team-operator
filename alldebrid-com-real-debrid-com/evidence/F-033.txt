## Reprodução

### Testes Realizados

1. GET /?return=<script>alert(1)</script>
   - Resposta: 200 OK, payload não refletido no HTML

2. GET /?lang=<script>alert(1)</script>
   - Resposta: 200 OK, payload não refletido
   - Language selector usa valores pré-definidos

3. GET /admin/?lang=<script>alert(1)</script>
   - Resposta: 200 OK (admin login page)
   - Payload não refletido

4. GET /SOGo/so/?module=<script>alert(1)</script>
   - Resposta: Página SOGo (diferente)

## Interpretação
O parâmetro `lang` aceita apenas valores pré-definidos (en-us, pt-br, etc.).
Valores inválidos provavelmente fallback para default (en-gb) sem refletir input.
CVE-2024-41959 pode ser específico para outra versão ou endpoint não testado.

## Impacto
XSS não confirmado neste vetor.
Podem existir outros endpoints vulneráveis (API, quarantine, etc.) não testados.
