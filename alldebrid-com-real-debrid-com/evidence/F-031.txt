## Interpretação
O servidor Postcow ACEITA bare LF (\n) como terminador de linha em comandos SMTP.
Isso é a condição primária para CVE-2023-51764 (SMTP Smuggling).
Se tivéssemos um IP não bloqueado, poderíamos:
1. Enviar comando DATA com \n
2. Injetar comandos SMTP adicionais no corpo do email
3. Spoofar remetentes, bypassar SPF/DKIM

## Impacto
- Spoofing de email (remetente forjado)
- Bypass de autenticação SPF/DKIM
- Envio de phishing a partir de mail.alldebrid.com
- Potencial para ataques de engenharia social direcionados

## Recomendação
- Configurar smtpd_forbid_bare_newline=yes no Postfix/Postcow
- Atualizar Postfix para >= 3.5.23, 3.6.13, 3.7.9, 3.8.4
- Verificar se mitigação já está em vigor mas não refletida no comportamento
- Testar com IP limpo (não Tor) para confirmar exploração completa
