## Reprodução

### Metodologia
1. GET /admin/ → extrair CSRF token do JS inline
2. POST /admin/ com login_user, pass_user, csrf_token
3. Verificar resposta: "Login failed" = falha, redirect = sucesso

### CSRF Token
- Extraído com sucesso (dinâmico por sessão)
- Valor exemplo: 20adf1df07ffbe082fbaf073960da2ce2fd8d2652f6d87aa46ab540782bd85b7
- Injetado via JS: $('<input>').attr('name', 'csrf_token').appendTo('form')

## Interpretação
O admin panel do Mailcow tem proteção CSRF + rate limiting.
Senhas comuns/complexas testadas sem sucesso.
Requer wordlist maior (rockyou, SecLists top 10000) para tentativa adicional.

## Impacto
Sem acesso ao admin panel, CVEs que requerem auth não podem ser explorados:
- CVE-2025-53909 (SSTI/RCE) — requer auth
- CVE-2022-31245 (OS Command Injection) — requer auth
- CVE-2026-40871 (SQL Injection) — requer auth

## Recomendação
- Tentar brute force com wordlist rockyou (via script paralelo)
- Verificar vazamento de credenciais em breaches (haveibeenpwned)
- Tentar IDOR no admin panel (se múltiplos admins existem)
