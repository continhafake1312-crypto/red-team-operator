# F-024 Caddy Combi — Nenhum painel/admin novo descoberto

**Alvo**: api-beta.stormapplications.com (75.2.96.173)
**Timestamp**: 2026-08-23T14:45:00Z
**Vetor**: CVE-2026-27588 (Host bypass) + CVE-2026-27587 (Path bypass)

## Resultado

**NENHUM painel, admin, setup ou página de instalação novo foi descoberto.**

A varredura combinada de 46 Host headers × 178 paths (total 356+ requests) não revelou nenhum endpoint além dos já documentados:
- `/status` — Info disclosure (já conhecido, F-006)
- `/api/login` — Handlebars HTML (já conhecido, F-004)
- `/admin` — ADMIN_AUTH_REQUIRED (já conhecido, F-007)

## Explicação

O Caddy do Discloud está configurado com:
1. **Vhosts específicos**: apenas `api-beta.stormapplications.com` e `mng.stormapplications.com` são válidos neste IP
2. **Vhost padrão (catch-all)**: serve página estática "Domain Configuration in Progress" para qualquer Host não reconhecido
3. **Proteção ADMIN_AUTH_REQUIRED**: aplicada a paths sensíveis (`/admin`, `/apps`, `/bots`) nos vhosts reais
4. **Backend Node.js/Express**: case-sensitive, não reconhece paths em maiúsculo

O host bypass (CVE-2026-27588) só permite acessar o vhost padrão, que não tem conteúdo dinâmico.
O path bypass (CVE-2026-27587) funciona mas o backend rejeita os paths com case diferente.

## Vetores Restantes

Para acessar painel/admin, os seguintes vetores permanecem:
1. Obter `x-storm-admin-key` válido (força bruta com wordlist maior)
2. Obter token Discord OAuth válido via phishing/social engineering
3. Explorar CVE-2026-27590 (FastCGI path splitting → RCE) se upload endpoint encontrado
4. Explorar CVE-2026-27586 (mTLS silent fail → bypass completo)
5. Explorar CVE-2021-32820 (Handlebars file disclosure via `layout` parameter)
