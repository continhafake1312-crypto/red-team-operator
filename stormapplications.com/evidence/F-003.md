# F-003 AWS Internal Infrastructure Disclosure
Alvo: mng.stormapplications.com
Severidade: Média
Timestamp: 2026-08-23T03:58:00Z

## Reprodução
```bash
curl -sk -D- https://mng.stormapplications.com/api/login | grep -i x-aws
```

## Response
```
x-aws-instance-id: i-0a06f4c3917127575
x-aws-region: eu-central-1
x-aws-instance-id: i-028e90aad8ec2bb5f
x-aws-region: eu-central-1
```

## Interpretação
Os headers HTTP expõem IDs de instância AWS e a região. Duas instâncias diferentes foram observadas, indicando load balancing. A região é eu-central-1 (Frankfurt). Esses IDs podem ser usados para ataques direcionados contra a infraestrutura AWS.

## Impacto
- Informação sobre infraestrutura interna exposta
- Instance IDs podem ser usados para ataques SSRF mais precisos
- Região AWS conhecida facilita ataques geolocalizados

## Recomendação
- Remover headers `x-aws-instance-id` e `x-aws-region` das respostas
- Configurar o balanceador para não vazar metadados
