## /login — Página HTML com Discord OAuth
Diferente dos outros endpoints, /login retorna uma página HTML completa com:
- Handlebars templating ({{{guild.banner}}}, {{{guild.icon_url}}}, {{{guild.name}}})
- Sistema de verificação Discord OAuth
- CSS customizado com design system do site
- JavaScript para extrair guild ID do state parameter
- "Developed by Storm Applications" no footer

## Impacto
Painel admin exposto publicamente (embora protegido por auth). A presença de
Discord OAuth indica que o painel usa login via Discord para autenticação.
Os headers customizados sugerem um sistema de admin keys para bypass.
