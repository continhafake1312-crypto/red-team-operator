## Análise

1. O Handlebars utilizado pelo mng pode ser versão >= 4.7.7 (patched)
2. Os parâmetros `layout`/`partial` são filtrados/sanitizados antes de atingir o motor
3. O `{{{guild.*}}}` triple-stash existe na página mas vem do Discord OAuth state, não de input direto do usuário
4. O parâmetro `template` retorna um JSON 404 de 20 bytes — indica que a rota trata query params de forma diferente mas não expõe leitura de arquivos
