# F-014 CVE-2026-27590 — Caddy FastCGI Path Splitting → RCE (NÃO CONFIRMADO)

**Alvo**: api-beta.stormapplications.com (Discloud/EC2 via Caddy reverse proxy, IPs 75.2.96.173 / 99.83.186.151)
**Severidade**: N/A (não confirmado)
**Timestamp**: 2026-08-23T14:10:00Z
**CVE**: CVE-2026-27590 (CVSS 9.8)

## Descrição
CVE-2026-27590 afeta Caddy < 2.11.1: o cálculo do split index para FastCGI SCRIPT_FILENAME/PATH_INFO é feito em uma cópia lowercase da path, depois o byte index é usado para fatiar a string original. Caracteres UTF-8 multi-byte que mudam de comprimento ao sofrer ToLower() (ex: 'İ' U+0130) causam path confusion, potencialmente permitindo execução de código arbitrário via upload de arquivo.

### 3. UTF-8 path confusion tests
```bash
# Testes com caracteres UTF-8 que mudam de comprimento ao fazer ToLower():
# /uploads/test%C4%B0.php (İ U+0130) — 404 NOT_FOUND
# /uploads/test%E2%82%AC.php (€) — 404 NOT_FOUND
# /uploads/test%C3%9F.php (ß) — 404 NOT_FOUND
# /uploads/test%C4%B1.php (ı) — 404 NOT_FOUND

# /uploads/test%E1%BC%80.php (ἀ) — 404 NOT_FOUND
```
Todos retornaram 404. Caminho /uploads/ não existe no backend.
