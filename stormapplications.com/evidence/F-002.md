# F-002 API de Pagamentos StorM Wallet — Documentação Pública

Alvo: wallet.stormapplications.com
Severidade: Média
Timestamp: 2026-08-23T04:25:00Z

## Descrição
A organização oficial `knstormapps` (StorM Applications) mantém documentação
pública da API de pagamentos PIX da StorM Wallet no repositório:
https://github.com/knstormapps/documentacao-wallet

## API Endpoints Documentados
| Método | Rota | Descrição |
|--------|------|-----------|
| GET | /api/v1/account | Validar API Key |
| POST | /api/v1/payments/create | Criar cobrança PIX |
| GET | /api/v1/payments/:id | Consultar pagamento |
| GET | /api/v1/payments | Listar pagamentos |
| POST | /api/v1/withdrawals/create | Criar saque |
| GET | /api/v1/withdrawals/:id | Consultar saque |

## Esquema de Autenticação
- Header: `x-api-key: SUA_CHAVE_AQUI`
- Alternativo: `Authorization: Bearer sk_live_...`
- Webhook: `X-Storm-Signature` HMAC-SHA256 com secret

## Campos do Pagamento PIX
- amount (number, máx 100.000)
- payerName (string, 3-100 chars)
- payerDocument (CPF)
- description (1-200 chars)
- externalId (string, max 100, usado como idempotência)
- metadata (objeto opcional)

## Webhook
- Eventos: payment.completed, payment.failed
- Headers: X-Storm-Event, X-Storm-Signature (HMAC-SHA256)
- URL configurável no painel da Wallet

## Confirmação de API Live
Request:
```
curl -s "https://wallet.stormapplications.com/api/v1/account" -H "x-api-key: test"
```
Response: `{"success":false,"error":"API Key inválida ou expirada"}`

## Impacto
A documentação da API é pública e fornece detalhes completos de integração.
Embora não contenha chaves reais (usa placeholders), expõe a superfície de
ataque da API de pagamentos.
