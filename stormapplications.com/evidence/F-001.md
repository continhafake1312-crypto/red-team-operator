# F-001 CORS Misconfiguration with Sensitive Header Exposure
Alvo: mng.stormapplications.com
Severidade: Alta
Timestamp: 2026-08-23T03:58:00Z

## Reprodução
```bash
curl -sk -X OPTIONS https://mng.stormapplications.com/api/login -D-
```

## Response
```
HTTP/2 200
access-control-allow-headers: Authorization, Origin, Accept, X-Requested-With, Content-Type, Access-Control-Request-Method, Access-Control-Request-Headers, x-storm-admin-key, x-admin-key, x-storm-audit-summary, x-discord-actor-id
access-control-allow-methods: GET,OPTIONS,POST,PUT,PATCH,DELETE
access-control-allow-origin: *
access-control-max-age: 86400
```

## Interpretação
O servidor permite requisições cross-origin de qualquer domínio (`Access-Control-Allow-Origin: *`) e expõe headers customizados de autenticação interna (`x-storm-admin-key`, `x-admin-key`, `x-storm-audit-summary`, `x-discord-actor-id`) na política CORS. Isso permite que qualquer site malicioso faça requisições autenticadas contra a API se a vítima estiver com sessão ativa.

## Impacto
- CSRF contra usuários autenticados
- Exfiltração de dados via origens maliciosas
- Headers de autenticação interna expostos podem ser usados para ataques de bypass

## Recomendação
- Restringir `Access-Control-Allow-Origin` para origens específicas e confiáveis
- Remover headers internos de autenticação do `Access-Control-Allow-Headers`
- Implementar CSRF tokens
