# F-007 api-beta.stormapplications.com — Painel Admin Exposto (ADMIN_AUTH_REQUIRED)

Alvo: api-beta.stormapplications.com/admin
Severidade: **Alta**
Timestamp: 2026-08-23T04:32:00Z

## Descrição
O endpoint `/admin` e todos os sub-endpoints em api-beta.stormapplications.com retornam `{"code":"ADMIN_AUTH_REQUIRED"}`, indicando que o painel administrativo existe e está acessível, porém protegido por autenticação. O acesso via `Authorization: Bearer <qualquer>` faz o bypass do Cloudflare 403.

## Endpoints Administrativos Confirmados
| Endpoint | Resposta |
|----------|----------|
| /admin | ADMIN_AUTH_REQUIRED |
| /admin/login | ADMIN_AUTH_REQUIRED |
| /admin/dashboard | ADMIN_AUTH_REQUIRED |
| /admin/users | ADMIN_AUTH_REQUIRED |
| /admin/config | ADMIN_AUTH_REQUIRED |
| /admin/settings | ADMIN_AUTH_REQUIRED |
| /admin/bots | ADMIN_AUTH_REQUIRED |
| /admin/bot | ADMIN_AUTH_REQUIRED |
| /admin/logs | ADMIN_AUTH_REQUIRED |
| /admin/api | ADMIN_AUTH_REQUIRED |
| /admin/health | ADMIN_AUTH_REQUIRED |

## Bypass de 403 Confirmado
- Sem header: `403 Forbidden` (Cloudflare)
- Com `Authorization: Bearer <qualquer>`: acesso ao backend (respostas JSON ou HTML)

## Impacto
A existência de endpoints administrativos expostos (embora com auth) combinada com o bypass de 403 via Authorization header representa um risco de segurança. Se as credenciais de admin forem obtidas (via brute-force, vazamento, ou outro vetor), o atacante teria acesso ao painel.

## Próximo passo
- Testar brute-force de senhas no /admin/login
- Testar JWT none algorithm no endpoint de login
- Testar SQLi/NoSQLi nos parâmetros de admin
- Testar bypass de autenticação via headers customizados (x-storm-admin-key, x-admin-key)

## Reprodução
```bash
curl -s "https://api-beta.stormapplications.com/admin" \
  -H "Authorization: Bearer teste"
```
