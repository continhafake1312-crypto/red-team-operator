# F-040 — Wallet SSRF /webhook/misticpay — NÃO CONFIRMADO
**Alvo:** wallet.stormapplications.com (172.67.150.146 / 104.21.39.240 via Cloudflare)
**Severidade:** Informação
**Timestamp:** 2026-08-24T06:00:00Z

## Resumo
O endpoint /webhook/misticpay é um receiver passivo para notificações da Mistic Pay. Não possui funcionalidade de fetch de URL externa. O payload `{"url":"..."}` é ignorado silenciosamente.

## Testes Realizados
1. POST /webhook/misticpay com `{"url":"https://oast.fun/storm-ssrf-test"}` → `{"success":true,"data":{"received":true}}`
2. POST com auth: `{"url":"http://169.254.169.254/latest/meta-data/"}` → mesma resposta
3. Schemas verificados: WebhookPayload aceita apenas `event`, `transactionId`, `status`, `amount`, `timestamp` — NÃO aceita `url`
4. Descrição da API: "Endpoint para receber notificações da Mistic Pay. Uso interno."

## Conclusão
SSRF NÃO confirmado. O endpoint é inbound (Mistic Pay → Wallet), não outbound (Wallet → URL externa).
