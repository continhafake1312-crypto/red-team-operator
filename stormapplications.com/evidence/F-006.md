# F-006 api-beta.stormapplications.com — Information Disclosure via /status Endpoint

Alvo: api-beta.stormapplications.com
Severidade: **Crítica**
Timestamp: 2026-08-23T04:30:00Z

## Descrição
O endpoint `/status` em api-beta.stormapplications.com expõe dados internos completos do backend Discloud, sem qualquer autenticação (basta o bypass `Authorization: Bearer <qualquer>` que muda de 403 para 404/200).

## Impacto
1. **Exposição total da base de clientes e preços** — concorrentes podem ver toda a estratégia de precificação
2. **IDs de bots Discord vazados** — permite ataques direcionados aos bots
3. **Configuração do sistema de auth exposta** — a URL de redirect do OAuth é conhecida
4. **Métricas de infraestrutura** — 643 apps, 28k+ usuários, uptime
5. **Informações sobre addons e funcionalidades** — mapeamento completo do produto

## Reprodução
```bash
curl -s "https://api-beta.stormapplications.com/status" \
  -H "Authorization: Bearer qualquer_coisa"
```

## Remediação
- Autenticar endpoint `/status`
- Remover dados internos (preços, bot IDs, configurações) de endpoints públicos
- Implementar rate limiting e validação de origem
