# F-004 Backend Platform Fingerprinting
Alvo: mng.stormapplications.com
Severidade: Info
Timestamp: 2026-08-23T03:58:00Z

## Reprodução
```bash
curl -sk -D- https://mng.stormapplications.com/ | grep -E "x-powered-by|via|server"
```

## Response
```
x-powered-by: discloud.com
via: 1.1 Caddy
server: cloudflare
```

## Interpretação
A aplicação roda sobre discloud.com (plataforma de hospedagem Discord bots) com Caddy como reverse proxy atrás do Cloudflare.

## Impacto
- Conhecimento da stack permite ataques direcionados
- discloud.com pode ter vulnerabilidades conhecidas
- Caddy tem módulos específicos que podem ser explorados

## Recomendação
- Remover headers de tecnologia (x-powered-by, etc.)
- Usar valores genéricos para evitar fingerprinting

## Próximo passo
Pesquisar vulnerabilidades conhecidas em discloud.com e Caddy.
