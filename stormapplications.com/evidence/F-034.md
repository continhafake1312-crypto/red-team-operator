## Method
For each secret, a JWT was generated with:
- Header: `{"alg": "HS256", "typ": "JWT"}`
- Admin payload: `{"typ": "admin", "id": "000...001", "slug": "storm", "e": "admin@s.com", "ip": "127.0.0.1", "iat": 1787549620, "exp": 1793000000, "iss": "StorMApps"}`
- User payload also tested

Tested against: `POST /auth/me` with `Authorization: Bearer <jwt>`

## Real JWT Cracking Attempt
The real storefront JWT was also tested against all secrets using `pyjwt.decode()` to verify signature — none matched.

## Conclusion
**NOT CONFIRMED.** The JWT secret is not a common/weak value. Likely a strong random secret generated by the Discloud platform. Further brute force would require:
- A large wordlist (rockyou, etc.)
- Hashcat mode 16500 for HMAC-SHA256 JWT cracking
- Estimated time: infeasible without knowing secret format
