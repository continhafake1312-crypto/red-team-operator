## Host Header Manipulation

Observou-se que o Caddy reverse proxy roteia baseado no Host header:
- Host: api-beta.stormapplications.com → JSON (/status data)
- Host: (qualquer outro) → HTML (página default Caddy/Next.js)

Isso confirma virtual hosting mas não constitui SSRF.

## Conclusão
**SSRF NÃO CONFIRMADO** em nenhum endpoint dos subdomínios testados. O backend da api-beta (Discloud) ignora parâmetros de URL não reconhecidos, e os endpoints administrativos exigem chave válida (x-storm-admin-key). Não foi encontrado endpoint que processe URLs fornecidas pelo usuário.
