# F-029: 2Captcha + Turnstile Bypass

**Date**: 2026-08-23
**Analyst**: Webapp Specialist
**Target**: `api-beta.stormapplications.com`
**Severity**: 🔴 HIGH (Auth Bypass)

## Summary

Turnstile captcha on `/auth/email`, `/auth/login`, `/auth/register`, and `/public/storefront/storm/auth/email` was successfully bypassed using 2Captcha service.

## Technical Details

**2Captcha API Key**: `3ff6b7b981be450b1cc93d846be77934` (found in `~/.config/opencode/.2captcha_key`)
**Turnstile Site Key**: `0x4AAAAAACKSTFyIPdWMxVoP`
**Page URL for token generation**: `https://api-beta.stormapplications.com/auth/login`

### Methodology

1. POST to `https://2captcha.com/in.php` with:
   ```json
   {"key": "3ff6b7b981be450b1cc93d846be77934", "method": "turnstile", "sitekey": "0x4AAAAAACKSTFyIPdWMxVoP", "pageurl": "https://api-beta.stormapplications.com/auth/login"}
   ```
   Response: `{"status":1,"request":"<REQUEST_ID>"}`

2. Poll `https://2captcha.com/res.php` every 2-3 seconds until status=1.

3. Average solve time: **5-10 seconds** per token.

### CRITICAL: Field Name Discovery

The API expects the turnstile token in field **`turnstile_token`** (NOT `turnstile`). This was discovered via analysis of JS chunks:

**Source**: `www.stormapplications.com/_next/static/chunks/0zhfw-qevbde8.js`
```javascript
loginEmail:(e,a,s)=>(0,t.api)("/auth/email",{method:"POST",body:JSON.stringify({email:e,turnstile_token:a,redirect_uri:s})})
```

Sending `turnstile` (wrong field) always returns `INVALID_CAPTCHA`.
Sending `turnstile_token` (correct field) bypasses captcha verification.

### Results

| Endpoint | Before Bypass | After Bypass |
|----------|--------------|--------------|
| `/auth/email` | `INVALID_CAPTCHA` | `USER_NOT_FOUND` (correct error for non-existent email) |
| `/auth/login` | `INVALID_CAPTCHA` | `FORBIDDEN` (proceeded to credential validation) |
| `/public/storefront/storm/auth/email` | `INVALID_CAPTCHA` | `SUCCESS` (sent verification code) |

### Recommendation

- Token single-use per request (timeout-or-duplicate if reused)
- Tokens expire within ~2 minutes
