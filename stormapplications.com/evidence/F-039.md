# F-039 — Wallet API Key with `all` Permissions + Payment/Transaction Creation
**Alvo:** wallet.stormapplications.com (172.67.150.146 / 104.21.39.240 via Cloudflare)
**Severidade:** Crítica
**Timestamp:** 2026-08-24T06:00:00Z

## Resumo
Registro no wallet sem captcha → JWT obtido → API Key `sk_live_f775e309e330d3e8a77b0cb142b0be82690d5c1cc989e6526b9d9acb1048402c` com permissão `all` (create_payment, read_payment, create_withdrawal, read_withdrawal) via POST /api-keys. A API Key é funcional e scoped ao usuário.

## Reprodução
1. POST /auth/register (sem captcha) → conta criada, JWT retornado
2. GET /auth/me (com JWT) → perfil confirmado (id: 6a8bdabb62a28410c434de8d)
3. POST /api-keys (com JWT) → API Key obtida
4. GET /api/v1/account (com API Key) → conta válida, webhookConfigured: false
5. POST /api/v1/payments/create (com API Key) → pagamento R$ 1.00 criado (id: 6a8bde0862a28410c434ea48)
6. POST /transactions/create (com JWT) → transação R$ 1.00 criada (id: 6a8bde9e62a28410c434ec5d)

## Outputs
- GET /api-keys: `{"data":[{"id":"6a8bdb0162a28410c434df83","name":"Pentest Key","keyPrefix":"sk_live_f775e309","permissions":["all"],"isActive":true}]}`
- POST /api/v1/payments/create: `{"success":true,"data":{"id":"6a8bde0862a28410c434ea48","amount":1,"status":"PENDENTE","pixCode":"00020126870014...","qrCode":"data:image/png;base64,..."}}`
- GET /api/v1/payments?limit=10: `{"items":[{"id":"6a8bde9e62a28410c434ec5d","amount":1,"status":"PENDENTE"},{"id":"6a8bde0862a28410c434ea48","amount":1,"status":"PENDENTE"}]}`

## Impacto
Atacante autenticado pode criar pagamentos e transações PIX com valor mínimo de R$ 1.00. O saldo da wallet é 0, impossibilitando saques, mas o fluxo de criação de PIX para recebimento está funcional. API Key com permissão `all` permite todas as operações financeiras.

## Recomendação
- Implementar captcha no registro
- Implementar validação de email (email verification)
- Implementar validação de CPF
- Restringir permissões de API Key por escopo mínimo
