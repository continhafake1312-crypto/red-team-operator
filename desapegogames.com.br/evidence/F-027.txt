## Vetores Testados e NEGADOS

### 1. Path Traversal / LFI [NEGADO]

CodeIgniter 3.x URI validation bloqueia `..` em path (HTTP 400 "disallowed characters").

```
/anuncio/video.html?anuncio=../../../../etc/passwd       → 200/8409 (int cast, anuncio=0)
/anuncio/video.html?anuncio=....//....//etc/passwd      → 200/8409 (int cast)
/anuncio/video.html?anuncio=php://filter/...resource=index → 200/8409 (int cast)
/anuncio/video.html?anuncio=../../../application/config/database.php → 200/8409
/perfil/..%2f..%2f..%2fetc%2fpasswd                      → 400/150 (CI3 URI validation)
/categoria/..%2f..%2fetc%2fpasswd                        → 400/150
/page/..%2fetc%2fpasswd                                 → 400/150
/busca.html?pesquisar=../../../../etc/passwd             → 200/4770 (tratado como termo de busca)
```

Nenhum `root:` em nenhuma resposta. CI3 faz int-cast no parâmetro `anuncio` e valida
URI chars (bloqueia `..`). Sem vetor de file inclusion.

### 8. HTTP Method Testing [NEGADO]

```
OPTIONS /admin/autenticacao/login → 200 (sem Allow header)
PUT     /admin/autenticacao/login → 200 (re-render page)
DELETE  /admin/autenticacao/login → 200
PATCH   /admin/autenticacao/login → 200
```

### 9. Cookie/Session Tampering [NEGADO]

```
ci_session = 32-char alphanumeric (server-side session ID, NÃO JWT/client-side data)
forged cookie (ci_session=FORGED) → 307 redirect /login
empty cookie (ci_session=)        → 307 redirect /login
no cookie                          → 307 redirect /login
session fixation (set ci_session antes do login) → server REGENERA session ID no login
  (pre-login: ci_session=pttst_fixation_X → post-login: ci_session=<novo ID>)
```

CodeIgniter 3 usa server-side session storage (arquivo). Cookie = session ID apenas.
Manipular cookie não altera session data. Session regeneration no login (fixation negado).
IP-based session validation (sess_match_ip): sessão invalidada quando Tor rotaciona IP.

## Conclusão

Attack surface da Rodada 3 EXAURIDA. Todos os vetores testados (path traversal,

session regeneration, IP-pinned sessions). O único vetor ativo remanescente é
password spraying (em execução, sem hits até o momento).
