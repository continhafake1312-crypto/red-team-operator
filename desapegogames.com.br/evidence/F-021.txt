# F-021 — Dovecot: TLSv1.3 hardened, AUTH=PLAIN pós-TLS, versão suprimida (DA build)

**Host:** 186.226.60.53 / .54 / .56 (portas 143/993 IMAP, 110/995 POP3)
**Serviço:** Dovecot "DA ready" (build DirectAdmin, versão SUPRIMIDA)
**Severidade:** BAIXO (TLS bem configurado, anti-enum, LOGINDISABLED pre-TLS)
**Status:** VALIDADO — cred stuffing limitado falhou; serviço hardened
**Operador:** exploit | **Data:** 2026-09-05T00:07Z

## Reprodução (não-destrutiva)

### Banner pré-TLS IMAP (porta 143) — LOGINDISABLED

```bash
$ printf "A1 CAPABILITY\r\nA2 LOGOUT\r\n" | proxychains4 -q nc -w 12 186.226.60.53 143
* OK [CAPABILITY IMAP4rev1 LOGIN-REFERRALS ID ENABLE IDLE SASL-IR LITERAL+ STARTTLS LOGINDISABLED] Dovecot DA ready.
* CAPABILITY IMAP4rev1 LOGIN-REFERRALS ID ENABLE IDLE SASL-IR LITERAL+ STARTTLS LOGINDISABLED
A1 OK Pre-login capabilities listed, post-login capabilities have more.
* BYE Logging out
A2 OK Logout completed.
```

Observações:
- **LOGINDISABLED** pre-TLS → login em claro DESABILITADO. Só permite LOGIN
  após STARTTLS. Excelente hardening (sem cred em sniffing).
- STARTTLS anunciado.
- Banner: "Dovecot DA ready" — **versão suprimida** (DirectAdmin build esconde
  o número de versão).

### Cred stuffing IMAP (1 tentativa, não-destrutiva) — FALHOU

```bash
$ proxychains4 -q curl -v -k --max-time 30 "imaps://186.226.60.53:993/INBOX" \
    --user "comercial@desapegogames.com.br:desapegogames" --request "LIST" "" "*"
> A002 AUTHENTICATE PLAIN AGNvbWVyY2lhbEBkZXNhcGVnb2dhbWVzLmNvbS5icgBkZXNhcGVnb2dhbWVz
< A002 NO [AUTHENTICATIONFAILED] Authentication failed.
* Login denied
```

Oracle confirmado: `A002 NO [AUTHENTICATIONFAILED]` = falha. `A002 OK ...` =
sucesso. `comercial@desapegogames.com.br:desapegogames` → **falhou**.

## Impacto

- **Login em claro (MITM):** NÃO (LOGINDISABLED pre-TLS, TLSv1.3 obrigatório).
- **Versão suprimida:** não confirma CVE-2020-24386/25275 (<2.3.13) — mas DA
  build recente shipa Dovecot ≥2.3.21 → provável patched.
- **Cert válido:** Let's Encrypt ECDSA, renovação automática aparente.
- **Cred stuffing:** sem wordlist de breach, baixa probabilidade. Senhas
  relacionadas ao domínio falharam.
- **Auth PLAIN pós-TLS:** seguro (cred sob TLS).

## Recomendação

- Manter LOGINDISABLED pre-TLS (já configurado).
- Manter TLSv1.3 (já configurado).
- Confirmar versão Dovecot internamente; se <2.3.13, atualizar (CVE-2020-24386
  access bypass, CVE-2020-25275 DoS).
- Adicionar fail2ban no Dovecot (cred stuffing).

## Notas

- Cred stuffing Dovecot limitado a 1 tentativa (mail fail2ban é agressivo
  em DirectAdmin; risco de bloqueio de conta real do owner).
- O username `comercial@desapegogames.com.br` (do OSINT) existe como mailbox
  local provável, mas sem senha conhecida. Não foi possível validar se a
  mailbox existe de forma não-destrutiva (AUTHENTICATIONFAILED = mesma msg
  para user inválido/senha errada → anti-enum).
