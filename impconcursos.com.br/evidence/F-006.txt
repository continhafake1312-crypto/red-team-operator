## Resumo
O PoC CVE-2025-29927 (header `x-middleware-subrequest`) foi executado de forma
não-destrutiva contra `chat.impconcursos.com.br`. **Nenhum bypass foi observado**
porque o host expõe **apenas a aplicação Typebot VIEWER**, que não possui rotas
protegidas por middleware de autenticação. O Typebot **builder** (que contém
`/dashboard`, `/typebots`, `/api/v1/*` protegidos por middleware) **não está
hospedado em infraestrutura do cliente** — está no lado do vendor (`core4.com.br`,
fora do escopo do engagement).

## Fingerprint do host (read-only)
- `X-Powered-By: Next.js` (versão não exposta via header).
- `buildId` pinado da homepage: **`Pd2AJTcTE36UcfIPNJIZ8`** (extraído de
  `__NEXT_DATA__` em `https://chat.impconcursos.com.br/`).
- `_buildManifest.js` enumerado em
  `/_next/static/Pd2AJTcTE36UcfIPNJIZ8/_buildManifest.js` → **apenas rotas do
  viewer**: `/[[...publicId]]`, `/old/[[...publicId]]`, `/_app`, `/_error`,
  `/api/health`, `/healthz`, `/api/typebots/:typebotId/blocks/:blockId/storage/upload-url`,
  `/api/v1/typebots/:typebotId/blocks/:blockId/storage/upload-url`.
- **Nenhuma rota de builder** (`/dashboard`, `/typebots`, `/typebots/public`,
  `/register`, `/login`, `/signin`, `/api/v1/typebots`, `/api/v1/workspaces`)
  existe como rota real — todas caem no catch-all `[[...publicId]]` e retornam a
  página "**404 The bot you're looking for doesn't exist**".

## Procedimento (detection-only)
Para cada rota candidata, comparou-se HTTP status + body length **SEM** o header
vs **COM** o header `x-middleware-subrequest`. Variações de nome do middleware
e profundidade testadas.

## Análise / Conclusão
1. O host é o **viewer** do Typebot: a rota `[[...publicId]]` (catch-all) serve a
   página pública de visualização de bots. Não há middleware de autorização
   nestas rotas (são públicas por design).
2. As rotas de dashboard/builder não existem neste host (buildManifest não as
   lista; `/api/v1/*` retorna 404 de rota inexistente, não 401/403 de auth).
3. Portanto **não há superfície para o CVE-2025-29927** aqui: o bypass atinge
   middlewares de auth que não estão presentes.
4. O `__ENV.js` (já documentado em recon) confirma `NEXT_PUBLIC_VIEWER_URL=
   https://chat.core4.com.br` — o **builder** provavelmente reside em
   `core4.com.br` (vendor), **fora do escopo** (`impconcursos.com.br`).
5. Não foi possível pinar a versão Next.js exata (X-Powered-By não expõe versão;
   sem `__NEXT_DATA__.nextVersion`). Mesmo que vulnerável, sem rota protegida o
   CVE não é explorável neste host.

## Impacto
Nenhum (teste negativo). O vetor CVE-2025-29927 **não se aplica** a
`chat.impconcursos.com.br`. Recomenda-se NÃO retestar este CVE neste host.

## Observação de valor (secundária)
A descoberta de que o host é viewer-only (e o builder é vendor-hostado) é
contexto útil: significa que o Typebot builder/dashboard do cliente **não está
sob controle direto da infra `impconcursos.com.br`** — qualquer gestão de
typebots/tenants passa pela plataforma do vendor `core4.com.br`, que está fora
do escopo autorizado.

## Reprodução

```
# via Tor (proxychains4 -> socks5 127.0.0.1:9050)
proxychains4 -q curl -s -A "Mozilla/5.0" https://chat.impconcursos.com.br/dashboard \
  -o /tmp/baseline.txt -w "%{http_code} %{size_download}\n"
proxychains4 -q curl -s -A "Mozilla/5.0" \
  -H "x-middleware-subrequest: middleware:middleware:middleware:middleware:middleware" \
  https://chat.impconcursos.com.br/dashboard -o /tmp/bypass.txt -w "%{http_code} %{size_download}\n"
diff /tmp/baseline.txt /tmp/bypass.txt   # -> identico
```
