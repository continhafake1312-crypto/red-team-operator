| NEXT_PUBLIC_UNSPLASH_ACCESS_KEY | lQ8EYPyAJz6ArYpmH3PSJ0b3u6JDUiEMb5EtmvVSCxA | LOW — public-by-design Unsplash key, but abusable for API quota theft / rate-limit consumption on the customer's key |

## Note
`NEXT_PUBLIC_*` keys are by Next.js design exposed to the client. The Unsplash/Giphy keys are intended to be public in browser apps. However, the `VERCEL_VIEWER_PROJECT_NAME=siterosaamazonica` is a deployment-metadata leak that reveals cross-customer information (the project name of a different core4 customer). This indicates chat.impconcursos.com.br and "siterosaamazonica" share the same core4.com.br Typebot platform.
