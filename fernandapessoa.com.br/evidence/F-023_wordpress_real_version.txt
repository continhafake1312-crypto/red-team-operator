**Alvos:**
- `https://fernandapessoa.com.br` (atrás Cloudflare — não bypassável via IP real)

- **`https://acaorelampago.fernandapessoa.com.br`** → WordPress **5.3.18** (NOVO SUBDOMÍNIO, via IP real)

**Severidade final:** Alta (versão desatualizada + CVEs + enumeração de usuários)

## Descoberta da versão real
httpx reportou "WP 7.x" — detecção incorreta (WP estável é 6.x). Bypass de Cloudflare via `--resolve`
para o IP real `187.45.185.33` revelou a versão verdadeira.

### matriculas.fernandapessoa.com.br
```
GET /feed/ →
  <generator>https://wordpress.org/?v=5.3.18</generator>
GET /readme.html → WordPress ReadMe (versão 5.x) — confirma
GET /wp-login.php → referências a /wp-includes/css/dashicons.min.css?ver=5.3.18
```
→ WordPress **5.3.18** (release de May 2022, ~4 anos desatualizado)

### acaorelampago.fernandapessoa.com.br (NOVO SUBDOMÍNIO descoberto)

## Impacto
- **Information Disclosure:** versão WP + usuário admin expostos publicamente (CWE-200).
- **Ataque direcionado:** admin user enum → brute force / credential stuffing em /wp-login.php.
- **Superfície de ataque expandida:** CVEs de WP <5.8.3 abrem vetor de SQLi/XSS/SSRF.
- **Plugins Elementor/jet-elements:** se desatualizados, RCE/XSS conhecidos.

## Reprodução
```bash
curl -skL --resolve matriculas.fernandapessoa.com.br:443:187.45.185.33 \
  https://matriculas.fernandapessoa.com.br/feed/ | grep generator
curl -skL --resolve acaorelampago.fernandapessoa.com.br:443:187.45.185.33 \
  https://acaorelampago.fernandapessoa.com.br/wp-json/wp/v2/users
```

## Recomendação
1. **Atualizar WordPress** imediatamente para ≥6.5 (mais recente estável).
2. Atualizar plugins Elementor/Elementor Pro/jet-elements para versões mais recentes.
3. **Desabilitar WP REST API users endpoint** (`/wp-json/wp/v2/users`) ou restringir por auth:
   - Plugin "Disable REST API" ou filter `rest_authentication_errors` / `rest_endpoints` para remover `users`.
4. Renomear usuário `admin` (id=1) para nome não óbvio.
5. Habilitar 2FA / limite de tentativas (Limit Login Attempts / cPHulk).
6. Validar CVE-2022-21661 SQLi com wpscan quando host não estiver rate-limited.
