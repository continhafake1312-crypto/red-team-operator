**Classificação:** Misconfiguration / SSRF (CWE-918) + DDoS Amplification (CWE-406)

**Resultado:** Server processou o pingback (retornou `<fault>` com faultCode 0 — processou mas source não continha backlink). O servidor **FEZ um HTTP request outbound** para `example.com` → **SSRF confirmado**.

## Interpretação

**xmlrpc.php está totalmente habilitado**, expondo três vetores:

1. **SSRF (CWE-918):** `pingback.ping` faz o servidor WP executar HTTP request outbound para URL arbitrária (source). Permite:
   - Port scanning interno cego (timing/error-based)
   - Acesso a serviços internos (metadata cloud, Redis, Elastic, etc.) se em nuvem
   - Bypass de firewalls de perímetro (server originate o request)

2. **DDoS Amplification (CWE-406):** Atacante envia 1 request `pingback.ping` → WP server faz múltiplos requests ao alvo vítima. ExploitDB 47800 — "WordPress Core < 5.3.x xmlrpc.php Denial of Service" — aplica-se à versão 5.3.18. `system.multicall` permite amplificação massiva (1 request HTTP → milhares de pings).

3. **Credential Brute-Force Amplification:** `system.multicall` permite testar dezenas de credenciais em 1 request HTTP → bypassa rate-limiting/limiter. Neste caso, 85 senhas testadas (combinadas com 49 do /wp-login.php via F-025 = 134 total), **nenhuma funcionou** → admin usa senha forte/não-padrão.

## Impacto

- **SSRF:** Atacante pode escanear portas/serviços internos do servidor (187.45.185.33) sem acesso direto
- **DDoS:** Site pode ser usado como amplificador de ataque DDoS contra terceiros (reputação + responsabilidade legal)
- **Brute-force:** xmlrpc multicall permite tentativa de senha em massa contornando limitadores de /wp-login.php
- Cred-stuffing foi NEGATIVO → não há foothold via senha fraca

## Recomendação

1. **Desabilitar xmlrpc.php completamente** (se não usado por plugins/mobile):
   ```nginx
   location = /xmlrpc.php { return 403; }
   ```
   OU no `wp-config.php`:
   ```php
   add_filter('xmlrpc_enabled', '__return_false');
   add_filter('xmlrpc_methods', function($m){ unset($m['pingback.ping']); unset($m['pingback.extensions.getPingbacks']); return $m; });
   ```

2. No mínimo, desabilitar `pingback.ping` (remove SSRF + DDoS amplification):
   ```php
   add_filter('xmlrpc_methods', function($methods){
     unset($methods['pingback.ping']);
     unset($methods['pingback.extensions.getPingbacks']);
     return $methods;
   });
   ```

3. Limitar `system.multicall` (mitiga brute-force amplification):
   ```php
   add_filter('xmlrpc_methods', function($methods){
     unset($methods['system.multicall']);
     return $methods;
   });
   ```

4. Implementar rate limiting no nginx para /xmlrpc.php (max 1 req/min/IP)
